# local-file-summary

## 用途

对单个本地文件生成一份结构化摘要，帮助用户快速理解文档用途、核心内容和当前重点。

## 建议输入

- `filename`
- `content`
- `userGoal`（可选）

## Prompt 文案

你正在帮助用户阅读一个本地文件。
请基于提供的文件名和文件内容，生成一份**简洁、准确、结构清楚**的摘要，帮助用户快速理解这份文档。

你的目标不是复述原文，而是提炼出最有价值的信息。
请优先回答：

1. 这份文件是做什么的
2. 它主要讲了什么
3. 当前最值得关注的重点是什么
4. 如果它和版本、方案、任务有关，下一步重点可能是什么

请遵守以下要求：

- 只基于提供的文件内容作答，不要编造文档中没有的信息
- 如果某项信息文档中没有明确提到，请直接说明“文档中未提及”
- 不要大段照抄原文
- 不要输出与文件无关的背景知识
- 术语尽量沿用原文表述
- 输出要面向第一次阅读该文件的人，保证易读、易扫读

如果用户提供了额外目标（`userGoal`），请在摘要中优先照顾该目标；如果没有，就按通用摘要方式输出。

请按下面结构输出：

**文档用途**  
用 1~2 句话说明这份文件的用途和定位。

**核心内容**  
提炼 3~5 条最重要的信息，使用简洁 bullet 表达。

**当前重点**  
如果文档涉及版本、方案、任务、架构，请总结当前最值得关注的重点；如果不适用，可说明“不适用”。

**补充说明**  
如果文档内容存在明显空白、待确认项、限制条件，或存在容易误解的点，请简短指出；如果没有，可省略本节。

## 建议插值方式

**文件名**  
`{{filename}}`

**用户目标**  
`{{userGoal}}`

**文件内容**

```text
{{content}}
```

## 简版（可选）

请基于给定的本地文件名和文件内容，输出一份简洁、准确的结构化摘要。
不要复述原文，不要编造文档中没有的信息。
优先说明：

- 文档用途
- 核心内容（3~5 条）
- 当前重点
- 可选的补充说明（如待确认点或限制条件）

如果用户提供了额外目标，请优先围绕该目标组织摘要。
如果某项信息文档中未提及，请明确说明“文档中未提及”。
