# Decisions: v0.6.1 General ReAct Agent Streaming

**Status**: Approved and implemented product/design baseline; the Tool-truth and trusted-URL correction reopened on 2026-09-23 was accepted and locally closed on 2026-09-24.

**Date**: 2026-09-22

本文件是 v0.6.1 实现的强制决策表。`MUST` 项不得在代码阶段自行弱化；需要改变时先更新本 workspace 并重新取得用户确认。

## Superseded Or Rejected Alternatives

| Alternative                                                       | Status and reason                                                                                                                                                                                      |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| v0.6.0 D032: Action text never public + every outcome runs Answer | **Superseded by D001–D005**；额外调用、延迟和过程说明丢失不再可接受。                                                                                                                                  |
| Reuse ordinary `text-*` with optional phase                       | Rejected；遗漏消费者会静默把 commentary 当最终正文。                                                                                                                                                   |
| Carry `pending` as an authoritative start-chunk field             | Rejected；它只是前端暂态，没有后端裁决价值；start 无 outcome，end 才携带 authoritative outcome。                                                                                                       |
| Buffer full model text until Tool decision                        | Rejected；破坏无 Tool 与 mixed turn 的即时流式体验。                                                                                                                                                   |
| Treat visible commentary as `reasoning-*`                         | Rejected；public action explanation 不等于 raw/hidden reasoning。                                                                                                                                      |
| Put commentary under the nearest Tool row                         | Rejected；并行与 Tool 间文本没有可靠一对一归属。                                                                                                                                                       |
| Implement Pencil `Nested Trace Row Disclosure` now                | Deferred；收益不足以覆盖安全、schema、replay、snapshot 和 UI 复杂度。                                                                                                                                  |
| Double every v0.6.0 budget                                        | Rejected；最坏累计输入成本和单进程占用过高，采用选择性约 1.5 倍。                                                                                                                                      |
| Run abnormal finalizer after cancellation/deadline                | Rejected；违反用户终止意图或硬时间边界。                                                                                                                                                               |
| Rewrite General ReAct as a Runnable/Chain tool loop               | Rejected；Chain 只适合固定顺序，动态 ReAct 需重新实现循环、状态、并发 Tool、profile timeout、logical/retry 预算、取消和 durable event ordering，风险更高而无净收益。                                   |
| Persist commentary as Chat Memory                                 | Rejected；过程说明不是 assistant final answer，会污染后续上下文。                                                                                                                                      |
| Remove URL provenance because a user supplied a link once         | Rejected；URL grant is not an interactive permission prompt, but it is an SSRF/secret/provenance boundary. Current user and trusted same-thread raw user turns are the only allowed sources.           |
| Use a URL catalog as proof of a prior successful read             | Rejected；catalog only authorizes a new explicit read. Existing storage has no trusted conversation-to-Run Tool transcript query; a future proof feature needs its own durable association and review. |

## Change Control

以下变化必须先回到本目录并取得用户确认：

- 修改三种 phase 的定义、解析条件或最终回答 authority；
- 改变任一固定预算、deadline、retry、timeout、parallelism、microbatch 或 active Run 数值；
- 让 commentary/pending 进入 server Memory、复制、feedback、follow-up 或最终回答；
- 恢复固定 Answer Phase，或让正常完成也调用 finalizer；
- 新增工具级 detail、raw Tool 输出、reasoning 展示或 server Trace storage；
- 让 Tasklist/Delivery/Image Agent 采用本 General Agent contract；
- canonical Pencil 与本决策表发生行为冲突。
