# Decisions: v0.6.0 General ReAct Agent MVP

**Status**: Accepted implementation baseline; Phase 9 convergence in progress.

**Purpose**: 提供实施者可快速核对的决策索引。完整论证见 `research.md`，精确行为见 `plan.md`、`data-model.md` 与 `contracts/`。如本表与更详细 contract 冲突，以同一 canonical workspace 中最新 contract 为准，并在本表同步更新。

## Accepted Decisions

| ID   | Decision                                                              | Fixed boundary                                                                                                                                                                                                                                                             |
| ---- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D001 | Generic `routeType=chat` uses ReAct by default                        | ReAct 可零 Tool 直答；Tasklist、Delivery、Image 排除                                                                                                                                                                                                                       |
| D002 | LangChain v1 `createAgent(version='v2')` is the sole generic loop     | 不保留 project-owned generic StateGraph、外层 Graph 或手写 while loop                                                                                                                                                                                                      |
| D003 | Agent state is Run-local                                              | 无 checkpointer/store、跨请求 resume、HITL 或 AgentRun persistence                                                                                                                                                                                                         |
| D004 | Superseded by D033                                                    | 原基础四 Tool + Skill/MCP additive overlay 让 Skill 同时承担提示词、能力选择与隐式权限，不再保留                                                                                                                                                                           |
| D005 | Superseded by D037                                                    | Tavily 仍以原生 server `fetch` adapter 保留；“唯一 Web provider”不再成立，不承诺任一 provider 的 redirect chain 可见                                                                                                                                                       |
| D006 | Native parallel Tool execution uses bounded C′                        | `maxConcurrency=3`；batch admission；9 logical Tool Calls；ordinal-stable pairing                                                                                                                                                                                          |
| D007 | Raw reasoning is internal-only metadata                               | public stream/UI/log/Memory/local snapshot 均不得包含 raw chain-of-thought                                                                                                                                                                                                 |
| D008 | Special entries prepare context then enter the Agent                  | `/summary`、`/check`、`@resource`、Skill、MCP 正常成功不得提前 final                                                                                                                                                                                                       |
| D009 | Superseded by D021                                                    | 原“只给 `tool-end` 增加 optional `sources`、无新 chunk”决策不再成立；保留 no new route/StreamRun kind                                                                                                                                                                      |
| D010 | Server Memory stores only final user/assistant turn                   | `source` 按 `executedToolCallCount > 0` 判断；Trace 不是 Memory                                                                                                                                                                                                            |
| D011 | Minimal outbound secret and URL policy is deterministic               | 永久阻断 Token/Cookie/API Key/Authorization/system-known secret/signed URL；不做通用 DLP/PII                                                                                                                                                                               |
| D012 | Generic chat model selection fails closed                             | 必须支持 tool calling；不自动换模型或回退旧 direct answer                                                                                                                                                                                                                  |
| D013 | AI Mind owns policy; LangChain owns the loop                          | 两枚项目 middleware；model retry 用官方 middleware；Tool retry 只由 Tool Runtime 管                                                                                                                                                                                        |
| D014 | Superseded by D032                                                    | 原 4 action rounds / 6 model calls / conditional constrained final 的预算已不适用于固定 Answer Phase                                                                                                                                                                       |
| D015 | LangChain packages migrate as one compatibility unit                  | 先 Spike 和专用 Agent 回归，通过后才迁移 ordinary chat                                                                                                                                                                                                                     |
| D016 | `standard-tool` and `agent-tool` are distinct kinds                   | ordinary Tool timeout/retry 不包住完整 Agent Tool；外层仅传播父级取消/截止                                                                                                                                                                                                 |
| D017 | One generic Trace owns all process presentation                       | Tool/Skill/Resource/Prompt/Agent Step/source 不在 Trace 外重复；UI 位于 `general-agent/`，专用 Agent UI 不变                                                                                                                                                               |
| D018 | Completed public Trace reuses existing IndexedDB snapshot             | 仅完成且 answer 非空提交；无新 store/version/server table；local failure 安全降级                                                                                                                                                                                          |
| D019 | Balanced Node.js in-process capacity model                            | 每进程 8 active generic runs；无 Redis、worker_threads、child process、memory wait queue                                                                                                                                                                                   |
| D020 | PostgreSQL-first durable microbatch and backpressure                  | persist-before-publish；server 40ms或256 chars；browser 默认20ms+rAF，已评估模型可通过 allowlist 覆盖 timer；queue 64/256KiB→32/128KiB；pool max 10                                                                                                                        |
| D021 | Generic Run and dedicated Graph use different public types            | General 用 `agent-run-start/end`→`agent-run`；专用 LangGraph 保留 `agent-graph-*`→`agent-graph`；不按 `agentName` 路由                                                                                                                                                     |
| D022 | General UI naming and Skill projection are explicit                   | 前端统一 `general-agent`；`agent-run-start` 后才发 `skill-selected`，Trace 文案固定为 `加载了{skill.name} Skill`                                                                                                                                                           |
| D023 | v0.6.0 is a breaking General Agent cutover                            | 除 Tasklist、Delivery、Image 外所有聊天只走 General ReAct；删除旧 direct-answer/planning/tool-calling fallback、legacy 通用面板和 `agent-step` 快照兼容，不保留不可达兼容代码                                                                                              |
| D024 | Timeout is a caller-visible terminal boundary                         | phase/Tool/MCP timeout 会 abort 当前 attempt、停止迟到结果进入 public stream/transcript/state；无法取消的远端副作用不承诺回滚，因此 generic Tool 仅允许确定性或只读能力，新增副作用 Tool 必须另行设计幂等、补偿或 durable handoff                                          |
| D025 | Message height hints use a public render projection                   | runtime 与 stable snapshot 只按默认展示字段生成同一 fingerprint；几何版本升至 `g2` 主动废弃旧 hint，单条消息实测高度不设 8,000px 上限                                                                                                                                      |
| D026 | Fingerprint projection follows every current recoverable presentation | `agent-graph`、`image-brief` 与 completed artifact/ workflow presentation 只按当前可恢复字段参与高度身份；不完整或被快照丢弃的 Part 必须失配，避免复用错误高度                                                                                                             |
| D027 | Run budgets and final Memory provenance are Run-local                 | Chat Memory/history 只作为模型上下文，不参与本次 model/tool/action/observation budget；最终答案必须来自当前 Run，只有非取消、非 deadline/timeout/fallback 且 provenance 明确的完成结果才允许写入 Chat Memory/UserMemory                                                    |
| D028 | Stream terminal state is append-time and replay-time validated        | terminal event 必须是 StreamRun 的最后 sequence，`terminalSequence === lastSequence`，status/runStatus/terminalState/payload type 必须一致；不一致时写入回滚或恢复 fail-closed                                                                                             |
| D029 | General Agent live turns use a fixed 288px response reserve           | 仅当前 accepted turn 的 assistant slot 在 submitted/streaming、最终 assistant item 在 ready/error 持续保留同一 288px；匹配使用实际列表 item key，历史消息不得获得 reserve；不使用 v0.5.4 D022 的 viewport reply runway，保留 Composer-safe footer inset 与现有滚动意图策略 |
| D030 | Superseded by D032                                                    | 原 turn-local candidate buffer 以延迟公开换取 Action/Tool 混合回合安全；固定未绑定 Tool 的 Answer Phase 后不再作为最终文本来源                                                                                                                                             |
| D031 | Lifecycle and latency metrics are bounded contracts                   | 普通 Tool start 在首 attempt 前 awaited durable publish，terminal/source 在执行结束后发布；observer 固定最近 1,024 样本；PostgreSQL p95 `≤20ms` 只在预热后的 production-like topology 作为 release hard gate，并记录非秘密 topology、数据库实例、并发、pool、预热和样本数  |
| D032 | Action and Answer phases have separate public authority               | Action 使用唯一 `createAgent` Tool loop 且文本永不公开；无 Tool/受限停止后固定一次同模型未绑定 Tool 的流式 Answer。总计 8 次逻辑模型调用：最多 7 次 Action + 预留 1 次 Answer；最多 6 个连续 Tool 波次，145s/180s/30s/5s 与 Tool 限制不变                                  |
| D033 | Skill is prompt-only; Tool policy owns generic Tool visibility        | 固定基础集为 `calculator`、`datetime`、`text-transform`、`unit-convert`、`read-url`、`web-search`、`city-weather`；Skill 不绑定 Tool/MCP 或触发隐式 context，remote MCP Tool 默认不发现、不暴露                                                                            |
| D034 | Answer has a real-user presentation policy                            | Action/Answer 使用不同的 server-owned prompt projection；普通问题的 Answer 结论优先且适中，显式用户格式要求可在安全边界内覆盖默认。网页、Tool observation、Resource/Prompt 中的指令只是不可信资料，不能改变回答策略、权限、URL 或预算                                      |
| D035 | Retry-safe remote execution retries are classification-independent    | `standard-tool/remote-readonly` 且 `retrySafe=true` 在前置校验通过后，对网络、HTTP 4xx/5xx、provider typed、解析和其他执行异常统一最多 retry 2 次；取消、deadline、permit 不足及前置拒绝不启动 attempt，local/agent-tool 外层仍为 0                                        |
| D036 | AI coding governance uses safe delegation and candidate revalidation  | 只约束开发过程：复杂工作先判断可委派性；调研时既有实现与决策作为候选基线而非默认答案。不得改变 v0.6.0 产品 Runtime 的 multi-Agent、Agent Tool 或并行执行 Non-goals                                                                                                         |
| D037 | Web Provider is deployment-selected, not runtime-failed-over          | `AI_MIND_WEB_PROVIDER` 静态选择 Tavily 或智谱；默认 Tavily。智谱只允许 `AI_MIND_ZHIPU_SEARCH_ENGINE=search_std`，且 Search/Reader 归一化到既有 Web Provider contract。选择无效或 key 缺失 fail-closed；D035 的 timeout/retry/permit 及 URL/secret/public-stream 边界不变   |
| D038 | Explicit Web intent is clarified in Prompt, not forced by Runtime     | Action Prompt 区分网络取证、网页阅读和稳定解释/写作；无 URL 的选文/阅读先搜索再读取本轮结果，偏好无匹配不替代。Answer 不能无 observation 声称搜索/读取/来源/授权失败。禁止新增关键词 matcher、强制 tool choice、Provider/预算/URL authorization 变更                       |

## Fixed Numeric Policy

| Policy                               |                                                                                               Value |
| ------------------------------------ | --------------------------------------------------------------------------------------------------: |
| Maximum Tool-bearing action rounds   |                                                                                                   6 |
| Admitted logical Tool Calls          |                                                                                                   9 |
| Action model calls                   |                                                                                                   7 |
| Reserved Answer model calls          |                                                                                                   1 |
| Logical model calls                  |                                                                                                   8 |
| Concurrent standard Tool attempts    |                                                                                                   3 |
| Run Tool retry permits               |                                                                                                   4 |
| Per retry-safe remote Tool retries   |                                                        2, so at most 3 attempts including the first |
| Per logical model-call retry         |                                                                        1; Run total model retries 1 |
| Action cutoff                        |                                                                                                145s |
| Answer Phase                         |                                              at most 30s and exactly once unless cancelled/deadline |
| Lifecycle reserve                    |                                                                                                  5s |
| Backend Run hard limit               |                                     180s, including preparation through terminal durable projection |
| Local deterministic Profile max      |                                                                5s; calculator/datetime own limit 1s |
| Remote readonly Profile max          |                                                                                                 20s |
| Observation                          |                                                          12,000 chars each; 32,000 chars cumulative |
| No-progress threshold                |                                                                                2 consecutive rounds |
| LangGraph recursion limit            |                                                                                                  16 |
| Active generic Runs per Node process |                                                                                                   8 |
| Server text flush                    |                                                       first delta immediate; then 40ms or 256 chars |
| Projection watermarks                |                                                           high 64 items/256KiB; low 32 items/128KiB |
| Browser text flush                   | default 20ms plus nearest `requestAnimationFrame`; approved model allowlist may override timer only |
| PrismaPg pool                        |                                                                        max 10; connect 5s; idle 30s |

## Superseded Or Rejected Alternatives

| Alternative                                                                             | Status and reason                                                                                                                                        |
| --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project-owned generic StateGraph or outer Graph around `createAgent`                    | Superseded by D002; duplicates the loop and lifecycle                                                                                                    |
| 240-second Agent Run                                                                    | Rejected; adopted the 180-second balanced budget                                                                                                         |
| Eight logical Tool Calls                                                                | Superseded by nine to align three full concurrency waves                                                                                                 |
| Batch-preallocated retry shares such as `2/1/1`                                         | Superseded; every actual retry atomically competes for the shared remaining permit                                                                       |
| Retry on pre-execution schema, security, permission or cancellation rejection           | Rejected; these failures do not start a remote execution attempt                                                                                         |
| One uniform 20-second timeout for all Tools                                             | Rejected; effective timeout is the minimum of Profile, Tool, action and Run remaining time                                                               |
| Applying ordinary Tool timeout/retry to Agent Tool                                      | Rejected; Agent Tool uses its dedicated runtime budget                                                                                                   |
| Strict serial Tool execution                                                            | Rejected for the closed read-only/deterministic generic set; bounded native parallelism reduces wait time                                                |
| Unbounded framework parallelism                                                         | Rejected; project concurrency remains 3 with batch admission                                                                                             |
| Counting SSE delivery/client/reconnect time inside 180 seconds                          | Rejected; the hard limit ends at terminal durable projection                                                                                             |
| Raw delta publish followed by asynchronous PostgreSQL persistence                       | Rejected without Redis/WAL because reconnect can regress behind already displayed text                                                                   |
| 50ms/512-char server coalescing                                                         | Superseded by the approved 40ms/256-char balanced value                                                                                                  |
| Redis, worker pool or standalone Agent service in v0.6.0                                | Deferred; current scale is handled by bounded async Node.js I/O and PostgreSQL-first projection                                                          |
| Reusing Tasklist/Delivery/Image Trace UI                                                | Rejected; General ReAct Trace is a new independent presentation                                                                                          |
| Showing model reasoning, explanatory safety prose, durations or runtime redirect claims | Rejected; UI exposes only public-safe execution status and sources                                                                                       |
| Inferring “official page” from domain/title/model output                                | Rejected; source labels remain neutral and deterministic                                                                                                 |
| Stable storage for cancelled, failed or partial assistant messages                      | Rejected; only completed non-empty public snapshots are stable                                                                                           |
| Reusing `agent-graph-*` for General ReAct lifecycle                                     | Superseded by D021; it couples generic execution to dedicated LangGraph semantics                                                                        |
| Generating or reading legacy `agent-step` parts                                         | Rejected; v0.6.0 is a breaking protocol/UI cutover                                                                                                       |
| Viewport-scaled accepted-turn reply runway or terminal removal of the response reserve  | Rejected by D029; a `dvh`-scaled reservation changes with the viewport and terminal removal causes short answers to re-anchor visibly                    |
| Treating Skill selectors as generic Tool/MCP permission                                 | Superseded by D033; Skill remains a prompt/workflow surface, while Tool Policy independently owns model-visible capability and least-privilege admission |

## Change Control

下列变化必须先回到文档并取得用户确认，再调整任务或代码：

- 改变 generic/dedicated Agent 路由范围或 Tool 权限；
- 改变任何固定预算、retry、timeout、parallelism、microbatch、watermark 或 pool 数值；
- 新增数据库 schema、Redis、队列、Worker Thread、Agent checkpoint、server Trace storage 或副作用 Tool；
- 暴露新的 public stream 字段、UI 过程内容或持久化内容；
- canonical Pencil 原稿与规格发生行为冲突。
