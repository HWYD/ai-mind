## Task Decomposition

### T1: 创建 Scheme Validator 纯函数

**优先级**: P0  
**依赖**: 无  
**预估工时**: 30min  
**风险等级**: 低

**任务描述**:

- 创建 `scheme-validator.ts`
- 实现 `validateScheme(uri: string, allowedSchemes: string[]): boolean`
- 解析 URI scheme（处理 `@scheme://` 格式）
- 大小写不敏感匹配
- 返回布尔结果（不返回原因，避免信息泄露）

**验收要点**:

- [ ] 正确解析 `@demo://` 格式
- [ ] 大小写不敏感匹配
- [ ] 不返回拒绝原因
- [ ] 纯函数，无副作用

**非目标保护**:

- ❌ 不处理路径验证
- ❌ 不处理错误消息
