# Context: 广州三天旅行计划

状态: Final
版本: v1.0
日期: 2026-08-01
场景ID: guangzhou-3-day-trip

## Product Context

- 目标是为一个第一次去广州的游客设计一份三天两夜的详细旅行方案。
- 读者是希望拿到可执行行程和 Task 清单的普通用户或旅行规划团队。
- 评价重点是行程是否合理、可执行，以及是否覆盖了广州的核心体验。

## Design Freedom

- Plan 可以根据需求推荐景点、美食、住宿区域、交通方式和预算参考。
- Task 可以包含行程安排、美食清单、交通衔接、注意事项和备选方案。
- 方案可以提出合理假设（出行季节、人数、预算档次、出发地），但必须把假设和需要用户确认的决策单独列出。
- 本案例只生成旅行计划和评审报告；AI Mind Runtime 不会在当前仓库中执行这些任务或进行实际预订。

## Review Focus

- General Reviewer：行程是否完整、可执行，每天安排是否合理，美食推荐是否覆盖广州特色。
- Risk Reviewer：天气风险、人流拥挤风险、交通延误风险、食品安全注意事项、预算超支风险。
- Boundary Reviewer：是否越界到机票酒店预订、签证办理、保险购买、周边城市游览或购物代购。

## Expected Delivery Shape

- 一份面向用户的广州三天旅行方案。
- 一份按依赖关系组织、可以交给执行方跟进的 Task 清单。
- 一份包含风险、假设、预算参考和下一步建议的评审报告。
