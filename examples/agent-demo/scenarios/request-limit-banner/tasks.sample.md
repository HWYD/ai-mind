## Task Decomposition

### T1: 创建 UsageBanner 组件骨架

**优先级**: P0  
**依赖**: 无  
**预估工时**: 30min  
**风险等级**: 低

**任务描述**:

- 在 `apps/webapp/components/chat/` 目录下创建 `usage-banner.tsx`
- 创建基础 React 函数组件
- 定义组件 Props 接口（空接口）
- 添加基础的 Tailwind 样式类

**验收要点**:
