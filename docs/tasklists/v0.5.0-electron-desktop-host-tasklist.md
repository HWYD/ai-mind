# v0.5.0 Electron Desktop Host 任务清单

## 已完成的工程工作

- 新增 Electron Forge Webpack 桌面 workspace、固定 build config、Squirrel.Windows 与 macOS arm64 DMG maker、package fuses 和制品校验工具。
- 新增严格的 Web compatibility API 与生产浏览器 security headers。
- 实现固定 Origin 的准入/恢复状态机、本地 protocol、profile 生命周期、诊断、原生 About 和单实例行为。
- 保持聊天、图像、受控 Agent、会话与 Stream recovery 继续由 Web 应用负责，同时增加收紧的桌面生命周期和原生保存策略。
- 增加桌面 stable/integration tests、Windows CI governance、会话滑动续期和 server-first 生产验证流程。

## 运营验收任务

以下是发布证据门槛，不代表仍有未实现的应用功能：

- 通过既有服务端部署链路发布 Web compatibility API 与 document security headers。
- 为精确的桌面候选版本运行生产 `verify-production.sh`。
- 验证通过后，为同一 source commit 构建未签名内部预览制品，并核验安装器、manifest、SHA-256 和 fuses。
- 在 Windows x64 与 macOS arm64 记录 fresh install 和同产品 overlay install smoke。
- 若服务端 contract 缺失或回退，持续暂停预览分发。

## 边界

v0.5.0 不包含公开分发、Developer ID 签名/公证、macOS Intel/universal 构建、自动更新、离线 AI Runtime、替代 Origin 或通用原生 bridge。
