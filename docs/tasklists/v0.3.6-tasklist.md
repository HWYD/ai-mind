## 交付说明

- public demo 现在同时保留两条受控入口：
    - `/tasklist + @demo://version-plans/*.md`
    - `/delivery-chain + @demo://scenarios/*/requirement.md` 或 `/delivery-chain <inline requirement>`
- `/delivery-chain` 只输出受控的 Plan、Task、Review 报告，不写代码、不读真实仓库、不做多 Agent。
