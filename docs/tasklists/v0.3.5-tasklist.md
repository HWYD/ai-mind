## 交付说明

- public demo 的 Agent 可读资源根现在是 `examples/agent-demo/`。
- `@demo://` 是唯一公开 Agent resource scheme。
- `@docs://` 在 public demo 中 fail closed。
- `/tasklist` 只接受 `@demo://version-plans/*.md`。
- `@` picker 只展示 demo version-plans，不再展示真实 `docs/versions/`。
- 快速访问默认使用已完成版本 `v034`，不引用未来版本。
