## 交付说明

- 普通 chat 现在具备 same-session refresh recovery。
- chat memory 使用独立 `langgraph_chat_memory` schema，不与 Tasklist Agent checkpoint 混用。
- hydrate 仍走安全 DTO；v0.4.2 仅新增可选 `thread-memory-status` 弱提示 chunk，不要求修改 frontend reducer public shape。
- chat memory 仍然只是 runtime bounded memory，不是产品级聊天历史表。

## 回归边界

- `/tasklist` 仍然只使用 Tasklist Agent 的 thread / checkpoint / AgentRun 语义。
- `/delivery-chain` 仍然保持 ControlledDeliveryManager + run-local RuntimeArtifact 边界。
- `delivery-chain-manager` scope 不向用户暴露普通 `tool-*` / `resource-*` transcript。
- Prisma schema / migration 不新增 chat history 业务表。
