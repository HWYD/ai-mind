# v0.1.1 Tasklist

- [x] Major Step 1：Plan Readiness Rules
    - 新增 `PlanReadinessResult`。
    - 基于规则判断 `ready / needs_review / blocked`。
    - 允许 `targetVersion` 从用户文本、标题或 URI 推断。
    - 不调用模型做 readiness 判断。

- [x] Major Step 2：Planning Decision Schema
    - 新增 5 类 `PlanningDecisionAction`。
    - 使用 schema 限制 action 结构、字段长度和 optional context URI 白名单。
    - 新增 `stopped` 等状态机状态。
    - `maxSteps` 从 8 调整为 12。

- [x] Major Step 3：Planning Decision + TasklistStrategy
    - 新增 Planning Decision Step。
    - 支持继续、补读上下文、澄清、带人工复核点继续、边界停止。
    - 新增 `TasklistStrategy`，用于控制 tasklist draft 的粒度、范围、分组和优先级。

- [x] Major Step 4：Optional Context Read
    - 最多读取一个白名单上下文。
    - `docs://...` 复用 docs resource adapter。
    - `project://latest-context` 复用现有 MCP 读取逻辑。
    - 读取失败降级继续，并写入人工复核点。

- [x] Major Step 5：Draft Prompt Uses Strategy
    - draft prompt 注入 `TasklistStrategy`。
    - Step 数量尽量落在 expected range。
    - Step 标题和 checklist 顺序参考 grouping / priority。
    - 保持来源方案 URI 和不写文件提示。

- [x] Major Step 6：Warning Disposition
    - 为 weak section 增加稳定 issue code。
    - 新增 `WarningDisposition`。
    - 结构硬伤触发 v2。
    - 弱质量项进入人工复核点，不单独触发 v2。

- [x] Major Step 7：Revision Effect
    - 新增 `RevisionEffectResult`。
    - 基于稳定 issue code 比较 v1 / v2。
    - final answer 输出修正效果摘要。
    - v2 仍 fail 时标记 blocked，但不生成 v3。

- [x] Major Step 8：AgentTracePanel 轻量展示
    - 复用现有 agent step stream。
    - 展示 decision / strategy / warning disposition / revision effect 摘要。
    - 展示 optional context 成功或失败状态。
    - 不展示完整 JSON、prompt、AgentState 或 draft diff。

- [x] Major Step 9：回归验证与文档资产收口
    - 覆盖 Agent runner 主路径和关键分支。
    - 覆盖 tasklist structure、chat-orchestrator、tool-binding 和 stream UI 回归。
    - 完成 typecheck 与 webapp lint fix。
    - 同步 runtime note、release note、README、公开 docs 和 tasklist。

- [x] Major Step 10：Agent Text Artifact 最终产物展示
    - 新增通用 `artifact-start / artifact-delta / artifact-end` text artifact 协议。
    - 在 `final_answer` 中只输出最终校验后的 tasklist artifact，不展示未校验 draft。
    - 前端新增 `AgentTextArtifactPanel`，并让 artifact 内容独立于普通 text part 聚合展示。
    - 覆盖 stream-core、schema、useChatStream、panel 和 Agent runner 回归。
