## 交付说明

- v0.3.4 只为 `/tasklist + @docs://versions/*.md` 接入 LangSmith observability。
- LangSmith 是外部观测层，不是业务事实源。
- AgentRun / AgentInterrupt 仍由 Prisma 业务表管理。
- LangGraph checkpoint 仍由 PostgresSaver 管理。
- GraphState 仍是 Tasklist Agent runtime 内部事实源。
- LangSmith trace 不决定 run status、不决定 resume、不决定 artifact 输出。

## 配置任务

- 本地 env 模板新增：
    - `LANGSMITH_TRACING`
    - `LANGSMITH_API_KEY`
    - `LANGSMITH_PROJECT`
- 生产 env 模板新增同一组配置。
- enabled 条件为 `LANGSMITH_TRACING=true` 且 `LANGSMITH_API_KEY` 非空。
- `LANGSMITH_ENDPOINT` 仅作为自托管或特殊 endpoint 的可选环境变量，不进入默认主配置。

## 上传字段边界

允许上传：

- `runId`
- `threadId`
- `assistantMessageId`
- `agentVersion`
- `graphVersion`
- `versionPlanUri`
- `modelId`
- `provider`
- `reasoningEnabled`
- interrupt / decision / result 类型
- review round、revision、finding count、duration 等计数和状态

禁止上传：

- 完整 GraphState。
- raw checkpoint。
- raw provider error。
- API Key。
- session cookie。
- ownerSessionHash。
- 完整 version plan 正文。
- 完整 prompt。
- 完整 optional context 正文。
- 完整用户 feedback。
- 完整 tasklist markdown。
- Prisma row 原始对象。
- request / writer / model client / AbortSignal / raw Error。

## 回归边界

- 普通聊天不触发 Tasklist LangSmith observer。
- reader-skill / utility-skill 不触发本 observer。
- MCP / ordinary Tool Calling 不触发本 observer。
- stream chunk schema 不变化。
- frontend message reducer 不变化。
- HITL decision payload 不变化。
- Graph nodes 不直接调用 LangSmith。
- LangSmith disabled / missing key / SDK failure 不影响 Tasklist Agent 主流程。

## 人工补验建议

如果要在真实 LangSmith 项目中做部署后补验，建议只跑一轮受控 `/tasklist + @docs://versions/*.md`：

1. 设置 `LANGSMITH_TRACING=true`。
2. 设置真实 `LANGSMITH_API_KEY`。
3. 设置 `LANGSMITH_PROJECT=ai-mind-dev` 或生产项目名。
4. 发起一次 Tasklist Agent。
5. 在 Strategy Review 选择 approve 或 respond。
6. 如触发 Tasklist Revision Review，再选择 approve 或 respond。
7. 在 LangSmith 中用 `runId` / `threadId` / `assistantMessageId` 搜索。
8. 人工确认 trace 中只有摘要 metadata，没有完整 prompt、feedback 或 tasklist markdown。
