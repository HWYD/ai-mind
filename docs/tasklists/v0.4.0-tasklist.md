## 交付说明

- `/delivery-chain` 仍然只有一个 public command，但内部主控已经从固定 stage main path 切到 `ControlledDeliveryManager`。
- `plan-subagent`、`task-subagent`、`review-subagent` 只在 delivery-chain runtime 内部作为受控 Agent-as-tool 存在，不进入全局用户可选 tool surface。
- RuntimeArtifact 只在本轮运行内部流转，不升级成 `@artifact://` 或持久化能力。
- workflow progress 继续存在，但不会变成 raw prompt / raw result / artifact transcript。

- 普通 resource/tool/prompt chunks 语义不变。
- Prisma schema / migration 不变。
