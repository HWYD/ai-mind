## 交付说明

- `UserMemory` 现在是同一 browser session 下跨 conversation 可复用的长期补充上下文。
- 当前主价值集中在长期偏好、稳定指令、工作流偏好、反复确认约束和稳定项目上下文。
- 长期记忆仍然是补充上下文，不替代 selected conversation 的短期 `ThreadState`。
- Store 不可用时，系统会安全降级到 no-long-term-memory mode，不影响正常聊天完成。

## 回归边界

- 不新增 ChatSession / ChatMessage 业务历史表。
- 不新增 memory-write public tool。
- 不修改 `@ai-mind/stream-core` chunk union。
- 不修改 frontend reducer public shape。
- 不把 Tasklist GraphState / HITL payload 接到 UserMemory。
- 不把 Delivery RuntimeArtifact / workflow progress / subagent raw result 接到 UserMemory。
