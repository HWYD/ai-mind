# v0.1.0 Tasklist

- [x] Major Step 1：Agent 入口与 Docs Resource Menu
    - 新增受控 docs catalog 接口，提供 `docs://versions/*.md`、architecture docs 和 `docs://README.md` 候选。
    - Composer Resource Menu 从接口加载本地 docs 候选，并保留 `project://latest-context` remote 示例。
    - 只在 `/tasklist + @docs://versions/*.md` 时识别为 Agent ready 分支。

- [x] Major Step 2：Agent Runtime Skeleton
    - 新增 `version-plan-to-tasklist-agent`、AgentAction、AgentState 和状态机。
    - 限制 step 数、自动修正次数和可选上下文读取次数。
    - 将 Agent stage 接入 `chat-orchestrator`，并放在普通 Composer Context 之前。

- [x] Major Step 3：Agent Step Stream 与 AgentTracePanel
    - 新增 `agent-step-start` / `agent-step-end` 流式协议。
    - 前端按同一次 Agent run 聚合多个 step。
    - Agent 模式下将 Resource / Tool 摘要归并到对应 step，避免重复顶层卡片。

- [x] Major Step 4：Version Plan Read 与 Plan Extract
    - 只读取用户显式引用的 `docs://versions/*.md`。
    - 生成 `VersionPlanExtract`，提取目标版本、目标、非目标、关键变更和测试计划。
    - 拒绝读取 `docs/tasklists/*`、`docs/releases/*` 和未显式引用的 version plan。

- [x] Major Step 5：validate_tasklist_structure
    - 新增 tasklist Markdown 解析、结构提取和结构校验模块。
    - 注册 `validate_tasklist_structure` Tool Definition。
    - 仅 Agent scope 默认允许调用，不暴露为普通问答可自由调用工具。

- [x] Major Step 6：draft_tasklist / revise_tasklist / final_answer
    - 基于 version plan 生成 `tasklistDraft v1`。
    - warning / fail 且可修正时最多生成 `tasklistDraft v2`。
    - final answer 输出可复制 tasklist 草稿、结构校验结论和人工确认点，不写文件。

- [x] Major Step 7：回归验证与文档资产收口
    - 覆盖缺少 version plan、正常生成、warning / fail 自动修正、普通 summary 和普通问答回归。
    - 完成相关单测、typecheck、lint 和 webapp 测试。
    - 同步 README、release note、runtime note、公开 docs 和博客草稿。
