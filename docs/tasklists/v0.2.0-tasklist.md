# v0.2.0 Tasklist

- [x] Major Step 1：LangGraph 依赖与 runtime config
    - 引入 `@langchain/langgraph`。
    - 新增 `getTasklistAgentRuntimeConfig()`。
    - 通过服务端 env 控制 legacy / graph、graph events、checkpoint 和 debug view。

- [x] Major Step 2：Runtime selector
    - 请求开始前选择 legacy runner 或 graph runner。
    - 不提供前端 runtime switch。
    - 不做运行中 fallback。

- [x] Major Step 3：共享 step operation
    - 抽取 tasklist Agent 业务步骤。
    - legacy runner 与 graph runner 复用同一组 operation。
    - 避免两套 runner 规则分叉。

- [x] Major Step 4：GraphState
    - 新增 graph runtime state。
    - `VersionPlanTasklistAgentState` 仍是业务事实源。
    - GraphState 只承接节点、路由、checkpoint 和摘要信息。

- [x] Major Step 5：StateGraph 主路径
    - 用 LangGraph `StateGraph` 表达 v0.1.1 主流程。
    - 覆盖 plan read、readiness、planning decision、optional context、strategy、draft、validation、revision effect 和 final artifact。

- [x] Major Step 6：Conditional edges
    - `PlanningDecisionAction` 映射为 graph route。
    - `WarningDisposition` 映射为 graph route。
    - optional context 最多读取一次，draft revision 最多一次。

- [x] Major Step 7：Graph runner parity
    - 覆盖 ready、needs_review、clarification、boundary stop、optional context 成功/失败、warning、fail、v2 和 final artifact 分支。
    - legacy fallback 保持可用。

- [x] Major Step 8：Graph stream chunks
    - 新增 node start / end。
    - 新增 route。
    - 新增 state patch summary。
    - stream-core 与 webapp schema 为协议事实来源。

- [x] Major Step 9：AgentTracePanel graph timeline
    - 前端 reducer 聚合 graph events。
    - Trace 面板展示 node、route 和 patch summary。
    - 兼容旧 `agent-step-*` 与 Agent Text Artifact。

- [x] Major Step 10：Development memory checkpoint
    - 支持 development-only `MemorySaver`。
    - graph run 绑定 threadId。
    - production 强制关闭。
    - 不做 resume / replay / history。

- [x] Major Step 11：Debug Summary
    - 新增脱敏 debug summary builder。
    - 新增 `agent-graph-debug-summary` chunk。
    - Trace 面板折叠展示 Debug。
    - 不展示完整 state、prompt、draft、resource 原文、tool raw output 或 env。

- [x] Major Step 12：版本资产收口与最终验证
    - 同步 runtime note、release note、README、公开 docs 和版本号资产。
    - release 默认仍保持 legacy，graph 通过服务端 env 显式开启。
    - 完成 Step 12 回归、lint、typecheck 和 diff 检查。
