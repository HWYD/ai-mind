# v0.5.2 Conversation Entry Without Scroll Flash 任务清单

## 已完成

- 建立当前会话消息归属和一次性历史进入 token，阻止延迟 A 会话内容影响当前 B 会话。
- 历史会话在隐藏树中完成消息视口到底定位与 rAF 校正后再揭示，避免可见滚动跳变。
- 将消息区收口为全高独立滚动视口；Composer 改为带渐变遮罩的浮层，并以真实高度加 54px 保护消息末尾。
- 以稳定 native scrollbar gutter 与实测 scrollbar 宽度保持 Composer 和内容列对齐。
- 将已有会话选择改为本地优先、后台串行确认；只读缓存可切换已有会话，写操作继续受限。
- 让推荐问题参与首次历史揭示，并限制动态禁用状态只更新最新 assistant 消息。

## 提交前验证

- 运行 root stable/integration 测试、lint、typecheck、build 与 `git diff --check`。
- 已在真实历史数据中复核长历史切换、刷新恢复、A→B、阅读位置保持、移动端、稳定 gutter 与推荐问题首帧；持久化失败、只读缓存、动态 Composer 与同帧揭示由自动化故障注入覆盖。
- 已在 Chrome DevTools 的 4 倍 CPU 降速下复核长历史 A→B，仅出现“加载状态 → 最新内容”两个可见阶段。
- GitHub Actions 在 main 完成 CI 后，创建 `v0.5.2` tag 与 GitHub Release。

## 边界

本版本不增加 cursor 分页、向上加载、虚拟列表、阅读位置/未读模型、服务端 API、数据库字段、Stream DTO 或 Electron IPC。
