## 交付说明

- pnpm 管理 workspace graph、lockfile、Catalog 和 dependency build scripts；Turbo 管理 task graph、并行执行与有限缓存。
- 根 lint/typecheck/test/build 是 canonical commands，package-level scripts 用于缩小故障范围。
- 数据库 migration、Prisma generation 和 runtime checkpoint setup 保持显式顺序，不隐藏在可复用缓存后。
- 生产发布继续使用现有 TCR、Compose、env、secret sync 和服务器部署脚本。

## 回归边界

- 不修改 ordinary chat、tool-assisted chat、Tasklist、Delivery、Agent/Tool/MCP 权限和前端展示。
- 不修改公开 API、DTO、stream protocol、数据库 schema 或生产 env。
- 不引入 affected-only execution、remote cache、Changesets、pnpm 11、`pnpm deploy`、Nx 或 Docker slimming。
