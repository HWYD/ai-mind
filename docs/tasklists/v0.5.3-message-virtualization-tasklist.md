# v0.5.3 Long Message Virtualization 任务清单

## 已完成

- 为所有非空聊天消息列表接入免费 `react-virtuoso`，建立统一的可视区渲染与动态高度测量路径。
- 收口滚动职责：Virtuoso 管理物理滚动，Scroll Policy 管理历史进入、流式跟随、阅读锁定和手动返回底部。
- 为文本、图片和执行过程卡片增加结构化高度估算，稳定图片各状态的卡片几何，并保留重要详情的离屏展开状态。
- 增加浏览器本地高度提示缓存，以严格布局签名匹配的稳定历史实测高度改善后续挂载；缓存不可用时自动降级。
- 修复历史会话刷新、切换和初始测量期间的骨架对齐、Composer 横向偏移、scrollbar 显示与返回入口闪现问题。

## 验收

- 自动化验证覆盖虚拟列表、动态高度、静态阅读、流式跟随、会话切换与本地持久化边界。
- 真实浏览器回归覆盖 1,000 条混合 fixture 与本地最长真实会话，以及桌面和移动端的刷新、拖拽、图片、详情和流式场景。
- 性能数据保留为后续优化诊断；本版本以正确展示、连续浏览和滚动行为通过为收口依据。

## 边界

- 不新增服务端分页、消息 API、Stream DTO、数据库 schema、跨设备阅读位置或 Electron IPC。
- 不恢复手工 `scrollTop` 控制，不启用第二个消息滚动 owner，不让虚拟列表内建 auto-follow 覆盖业务策略。
