## 交付说明

- `/delivery-chain` 继续保持固定顺序的受控 workflow，不新增新的 public command。
- 过程展示首版只绑定 `/delivery-chain`，不影响 `/tasklist` 或普通聊天消息的既有展示路径。
- workflow progress 是 presentation-level trace，不进入 DB、checkpoint、artifact store 或 event store。
- step details 只展示 curated safe summary，不自动转发普通 tool/resource/prompt 事件。
