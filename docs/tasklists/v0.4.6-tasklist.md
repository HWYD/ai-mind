## 交付说明

- `UserMemory` 继续是同一 browser session 内跨 conversation 可复用的长期补充上下文；selected conversation 的 `ThreadState` 仍是短期事实源。
- semantic retrieval 只使用 vector candidates；成功时最多注入 3 条记忆，失败或不相关时允许注入 0 条。
- embedding vectors、scores、raw query 和 provider/store 原始错误不会进入 hydration、Conversation Registry、stream 或前端公开状态。

## 回归边界

- 不新增 UserMemory 写入来源、memory search tool、RAG、独立向量数据库、Memory Inspector 或账号级同步。
- 不修改 Tasklist checkpoint/resume、Delivery run-local、stream-core chunk union、frontend reducer public shape 或 Prisma 数据模型。
