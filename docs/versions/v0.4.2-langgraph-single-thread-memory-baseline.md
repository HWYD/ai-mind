# AI Mind v0.4.2: LangGraph Single Thread Memory Baseline

## 摘要

v0.4.2 为当前唯一普通聊天会话引入了 LangGraph thread memory baseline。

新的普通 chat 主链路变为：

```text
ordinary text chat
  -> resolve browser session
  -> derive chat:${sessionHash}
  -> read ThreadState from chat memory checkpoint
  -> build memory context from summary + pinned decisions + recent messages
  -> take only the latest frontend user message as current turn input
  -> run ordinary chat / reader / docs-summary text path
  -> stream completed assistant answer
  -> append completed user/assistant text turn once
  -> compact when recent messages exceed threshold
  -> hydrate via GET /api/chat/thread after refresh
```

## 为什么需要这个版本

在 v0.4.1 之前，AI Mind 的普通 chat 仍然是纯前端内存态：刷新页面后 recent messages 会丢失，长对话也缺少受控的上下文压缩基线。

v0.4.2 的目标是：

- 为当前单浏览器会话提供 same-session refresh recovery。
- 通过 bounded recent messages、summary compaction 和 pinned decisions 控制输入上下文体积。
- 保持 Tasklist Agent HITL / checkpoint / resume 与 Delivery Chain run-local artifact 边界不变。
- 不把普通 chat memory 直接升级为多会话历史产品或 Prisma 业务表。

## 核心设计

### 单独的 chat memory thread 和 schema

- thread id 使用 `chat:${sessionHash}`。
- `sessionHash` 来自现有 session cookie 的服务端派生值，不暴露 raw session id。
- chat memory 使用独立 checkpoint schema：`langgraph_chat_memory`。
- Tasklist Agent 继续使用 `langgraph_checkpoint`。

### Bounded ThreadState

ThreadState 只保存：

- recent text-only user / assistant messages
- `summary`
- `pinnedDecisions`
- `lastCompactedAt`

本版明确排除：

- tool / MCP transcript
- Tasklist GraphState / HITL state
- Delivery RuntimeArtifact / workflow progress
- raw prompt / provider response / stack trace

### Safe hydration

- 新增 `GET /api/chat/thread`
- hydrate DTO 只返回 `threadId`、`messages`、`summaryPreview?`、`pinnedDecisions`、`restored`
- DTO 在服务端和前端消费边界都做严格校验
- hydrate 不依赖新增 stream chunk；v0.4.2 仅新增可选 `thread-memory-status` 弱提示 chunk，现有 reducer public shape 保持不变

### Context compaction

- recent messages threshold: 8
- summary target: 2500 字
- pinned decisions: 最多 20 条
- compaction 在 completed assistant turn 之后执行
- compaction 失败时 no-op，不破坏已有 memory，也不影响已完成回答

## 与 v0.4.1 的关系

| 维度                     | v0.4.1                               | v0.4.2                                       |
| ------------------------ | ------------------------------------ | -------------------------------------------- |
| 版本主线                 | Delivery Chain review-group 并行评审 | 普通 chat 单会话记忆基线                     |
| 普通 chat 刷新恢复       | 无                                   | 有                                           |
| 普通 chat 上下文压缩     | 只有前端近轮上下文                   | recent messages + summary + pinned decisions |
| checkpoint schema        | `langgraph_checkpoint`（Tasklist）   | 新增 `langgraph_chat_memory`                 |
| hydrate route            | 无                                   | `GET /api/chat/thread`                       |
| Tasklist / Delivery 边界 | 已固定                               | 保持不变                                     |

## 非目标

- 不做多会话历史列表
- 不做 ChatSession / ChatMessage Prisma 业务表
- 不做长期记忆、vector memory、Memory Inspector
- 不做 chat memory 的 HITL / checkpoint resume 产品能力
- 不做 tool-calling transcript persistence
- 不把 Tasklist / Delivery 内部 runtime state 纳入 chat memory
