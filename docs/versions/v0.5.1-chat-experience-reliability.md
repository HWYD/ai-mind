# AI Mind v0.5.1：Chat Experience & Image Reliability

## Summary

v0.5.1 收口日常聊天体验与 `/image` 的可靠性：会话导航更完整，图片在当前浏览器或 Electron profile 刷新后可恢复，偶发生成失败具备受限重试。

## Goals

- 将近期会话统一扩至 50 条，并优化桌面长标题可见性。
- 为生成图片提供连续的加载反馈和受限本地恢复。
- 降低图像规划误拦截及确定性 Provider 临时故障造成的失败。
- 在桌面侧栏和移动抽屉提供项目入口。

## Non-goals

- 不提供无限历史、搜索、跨设备同步或服务端图片库。
- 不持久化 Provider URL、Prompt、Base64 或 Object URL。
- 不改变 Stream DTO、公开内容路由安全校验或 Electron IPC 边界。

## Key Changes

- 最近会话从 10 条扩至 50 条；桌面长标题在溢出时按悬浮或焦点单次展示末尾内容。
- 已验证的图片 Blob 以 30 张或 100 MiB LRU 缓存到当前 profile，可在刷新后预览和下载；无法恢复时展示失效占位。
- 图像生成和结果读取共用固定画幅流光占位，避免重复 loading 卡片。
- 每个图像规划节点仅对瞬时故障最多请求 3 次；单次图像规划最多 5 个逻辑节点。Provider 只对明确的 `429`/`5xx` 有限重试。
- 增加固定访客菜单：浏览器新开 GitHub 标签，Electron 复制项目链接；移动端同样可用。

## Verification

根目录与全部 workspace 已锁步使用 `0.5.1`。冻结安装、stable/integration 测试、Windows 桌面打包与制品校验，以及三个 Linux/amd64 Docker 构建目标均已通过。远端 macOS arm64 打包在提交后由 GitHub Actions 验证。

## Outcome

本版本已达到发布候选状态；它提升既有体验和可靠性，不引入新的服务端持久化或桌面原生权限。
