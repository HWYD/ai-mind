# AI Mind v0.2.4：Tasklist Agent Graph Single State Model Consolidation

## Summary

v0.2.4 是一次架构收口版本，不新增 Agent 能力。  
本版在 v0.2.3 `/tasklist + @docs://versions/*.md` 已固定走 Graph Runtime 的基础上，继续把 Tasklist Agent 的内部运行态收口为 GraphState 单一事实源，移除生产 graph nodes 对旧整包 AgentState adapter 的依赖。

## Goals

- `/tasklist + @docs://versions/*.md` 继续只走 Graph Runtime。
- GraphState 成为 Tasklist Agent 生产路径的唯一内部运行态事实源。
- Graph nodes 直接读取 GraphState 分区。
- Graph nodes 返回明确 GraphState patch，GraphState reducer 负责合并分区 patch。
- Graph routes 继续基于显式 GraphState 字段判断。
- 移除生产路径中的 `toVersionPlanTasklistAgentState()` 和 `createGraphStateUpdateFromAgentState()` 过渡依赖。
- 移除旧 `VersionPlanTasklistAgentState` 类型和旧状态机 apply / validate API。
- 保持 tasklist artifact、stream chunk、AgentTracePanel 和 Graph Debug Summary 兼容。
- 不提前实现 HITL、Resume、Run History 或持久化。

## Key Changes

### Single GraphState Model

Tasklist Agent 初始运行态现在直接从 `runId`、显式 `versionPlanReference` 和 runtime config 创建：

```text
runVersionPlanTasklistGraph()
  -> createInitialVersionPlanTasklistGraphState()
  -> LangGraph StateGraph
```

GraphState 继续使用既有分区：

- `input`
- `source`
- `planning`
- `tasklist`
- `execution`
- `output`
- `graph`
- `threadId`

本版没有新增未来能力字段。

### Graph Nodes Without Whole-State Adapter

Graph nodes 不再执行下面的过渡流程：

```text
GraphState -> AgentState -> domain step -> AgentState -> GraphState patch
```

现在改为：

```text
GraphState -> domain operation -> GraphState patch
```

领域 guard、tasklist validation、warning disposition、revision effect 和 artifact 输出逻辑继续保留，只是输入输出边界更贴近 Graph Runtime。

GraphState patch 采用分区合并语义：node 只返回本节点负责的字段变化，`planning`、`source`、`tasklist` 和 `execution.counters` 不需要由调用方手动回填完整分区。Graph route 成功路径优先依据业务字段，例如已读取的 `source.versionPlan` 和已生成的 `planning.strategy`，而不是只看流程游标。

### Protocol Compatibility

本版保持以下协议稳定：

- `/tasklist` 入口。
- tasklist markdown artifact 格式。
- `artifact-start` / `artifact-delta` / `artifact-end`。
- graph node / route / state patch events。
- Graph Debug Summary。
- AgentTracePanel 消费结构。

Graph Debug Summary 仍只输出白名单摘要，不输出完整 GraphState、prompt、API Key、资源正文、tasklist draft 正文或 raw error。

## Non-goals

本版不做：

- HITL
- LangGraph `interrupt()`
- Resume API
- Run History
- AgentRun 数据库存储
- Redis / usage counter
- 新 Agent 类型
- 自由 tool calling
- 前端 UI 重做
- tasklist artifact 格式变更
- stream-core 外部协议变更
