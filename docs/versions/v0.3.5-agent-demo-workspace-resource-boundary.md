# AI Mind v0.3.5: Agent Demo Workspace Resource Boundary

## 摘要

v0.3.5 是一个 public demo 边界收口版本。
它不扩展 Tasklist Agent 的权限，也不改 Graph、HITL、checkpoint resume 或 LangSmith 语义；它做的是把公开 demo 的 Agent 可读资源严格收口到 `examples/agent-demo/`，并让 `/tasklist` 从 `@docs://versions/*.md` 迁移到 `@demo://version-plans/*.md`。

## 为什么需要这个版本

在 v0.3.4 之前，public demo 的 Tasklist Agent 仍然依赖真实 `docs/versions/*.md` 作为输入来源。这会带来几个问题：

- public demo 会直接读取真实项目文档目录，资源边界不够清晰。
- `docs/` 同时承担公开文档展示和程序可读资源，两种角色混在一起。
- `@` picker 未来容易继续外溢到真实仓库目录。
- 后续 `/plan`、`/task`、`/review`、`/delivery-chain` 如果继续复用这条入口，会把 demo 和真实项目目录耦合得更深。

v0.3.5 的目标就是先把公开 demo 的“资源根”收住，再继续往 Delivery Chain 方向演进。

## 本版做了什么

### 1. 新增 Agent Demo Workspace

新增 `examples/agent-demo/` 作为 public demo 的唯一 Agent resource root，内部只放 demo 语料，不放真实源码。

结构包括：

- `README.md`
- `demo-manifest.json`
- `version-plans/`
- `scenarios/`
- `rubrics/`
- `governance/`

其中 `version-plans/` 只保留少量已完成的重要版本和测试版本，不放 v0.3.5 / v0.3.6 这类未完成或未来版本。

### 2. 新增 `@demo://` scheme

public demo 新增 `@demo://` scheme，严格映射到 `examples/agent-demo/`。

允许读取的资源包括：

- `@demo://README.md`
- `@demo://demo-manifest.json`
- `@demo://version-plans/*.md`
- `@demo://scenarios/*/*.md`
- `@demo://rubrics/*.md`
- `@demo://governance/*.md`

resolver 会执行：

- path normalize
- root boundary check
- extension allowlist
- file size limit
- hidden path / traversal / absolute path 拒绝

### 3. `@docs://` 在 public demo 中 fail closed

`@docs://` 不再保留为 public Agent resource scheme。
如果用户继续输入 `@docs://`，系统会明确提示该 scheme 已下线，并引导改用 `@demo://version-plans/*.md`。

这意味着仓库里的 `docs/`、`specs/`、`apps/`、`packages/` 仍然可以作为项目文档或源码存在，但不再是 public demo 可读资源。

### 4. Tasklist Agent public demo 入口迁移

public demo 中的 Tasklist Agent 现在使用：

```text
/tasklist + @demo://version-plans/v034-langsmith-observability.md
```

运行时仍保持这些不变：

- Graph topology
- HITL decision contract
- checkpoint resume
- AgentRun / AgentInterrupt
- LangSmith metadata 语义

字段名 `versionPlanUri` 保留，只是值从旧的 docs scheme 迁移为 `@demo://version-plans/*.md`。

### 5. `@` picker 和快速访问只面向 demo version-plans

`@` resource picker 不再展示真实 `docs/versions/`，只展示 `examples/agent-demo/version-plans/` 中由 manifest 列出的 demo version-plans。

首次出现的快速访问中新增 Tasklist Agent demo 示例，默认填入：

```text
/tasklist + @demo://version-plans/v034-langsmith-observability.md
```

### 6. 小屏移动端做最小 UX polish

本版顺带优化了 public demo 入口在小屏下的密度：

- textarea 初始高度压缩为一行
- 模型选择器字体和 padding 变小
- slash command popup 和 resource popup 的标题、描述、item padding 更紧凑

这些调整只影响小屏移动端，不改 desktop，不改 reducer，不做整体 UI 重构。

## 明确不做

v0.3.5 不做以下内容：

- 不新增 Controlled Delivery Chain Agent
- 不实现 `/plan`、`/task`、`/review`、`/delivery-chain`
- 不实现 `@artifact://`
- 不做 artifact handoff 或真实 artifact persistence
- 不新增 HITL 流程
- 不修改 Tasklist Agent Graph topology
- 不修改 HITL contract
- 不修改 stream protocol
- 不修改 frontend reducer 数据结构
- 不修改 Prisma schema
- 不修改 PostgresSaver schema
- 不改变 v0.3.4 LangSmith observer 语义

## 验证重点

本版重点验证：

- `@demo://` 可读
- `@docs://` 被拒绝
- path traversal / absolute path / 未知扩展名被拒绝
- `/tasklist + @demo://version-plans/*.md` 可触发 Tasklist Agent
- `@` picker 只展示 demo version-plans
- 快速访问默认使用已完成版本 `v034`
- 小屏移动端样式更紧凑，桌面端不回归

## 对后续版本的意义

v0.3.5 不是 Delivery Chain 本身，而是 Delivery Chain public demo 的前置边界版本。
它先把可读资源根、picker 数据源和公开入口收口干净，给后续基于 `@demo://` 的 `/plan`、`/task`、`/review` 和 `/delivery-chain` 铺路。
