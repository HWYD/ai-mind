# AI Mind v0.5.2：Conversation Entry Without Scroll Flash

## Summary

v0.5.2 收口历史会话的进入体验：用户从侧栏、移动抽屉选择既有会话，或刷新恢复上次会话时，首个可见的真实历史状态直接位于最新内容区域，不再先展示历史顶部或上一会话残留。

## Goals

- 让已有会话以“加载骨架 → 已定位的最新消息”两个可见阶段进入。
- 让消息视口独立于页面文档滚动，并覆盖聊天列完整高度。
- 保持 Composer 悬浮，同时以真实高度保护最新消息，并稳定对齐消息内容列。
- 让本地会话选择和本地快照恢复先于服务端选中偏好确认生效。
- 保持流式自动跟随、用户上滑锁定与“回到底部”语义。

## Non-goals

- 不新增 cursor API、尾页分页、向上加载或虚拟列表。
- 不新增阅读位置、未读游标、数据库字段、Stream DTO 或 Electron IPC。
- 不改变既有聊天 Runtime、持久化模型和服务端会话权威边界。

## Key Changes

- `useChatStream` 用 `messageConversationId` 标识当前消息归属，并用单调递增的 `historyEntryReady` token 触发一次历史进入定位；本地有效快照在远端验证前即可 ready。
- 页面在 `useLayoutEffect` 中先完成滚动条宽度测量和隐藏消息树的到底定位，再在可取消的 `requestAnimationFrame` 校正后揭示内容。
- 消息视口成为唯一 `overflow-y-auto` 容器，使用 `scrollbar-gutter: stable`；Composer 作为底部浮层，右侧按实测滚动条宽度收缩。
- `ResizeObserver` 以 Composer 真实高度加 54px 设置消息末尾安全区，并仅在用户原本贴底时跟随 Composer 或消息内容的后续增高。
- 已有会话本地优先选中；后台本地索引和 selected-preference 写入按最新选择串行收敛，快速 A→B 不会被过期结果覆盖。只读缓存仍允许在已有本地会话间切换。
- 推荐问题在首次隐藏布局中与最新 assistant 回复共同挂载；暂不可交互时禁用按钮，而不延后插入整个推荐区域。

## Verification

已通过冻结依赖安装、stable/integration 测试、lint、typecheck、build 与 `git diff --check`；并在真实历史数据中复核了桌面/移动端长历史切换、刷新恢复、快速 A→B、阅读位置保持、稳定 gutter、推荐问题首帧与 4 倍 CPU 降速。远端 GitHub Actions 全部通过后创建 `v0.5.2` tag 和 GitHub Release。

## Outcome

本版本为后续“尾页优先 + 向上加载 + 端锚定虚拟化”提供稳定的消息视口和底部锚定基础，但不提前引入分页或虚拟化依赖。
