# AI Mind v0.4.12：Image Generation Agent

## 摘要

v0.4.12 增加受控的 `/image` 单张文生图闭环：

- 用显式 `/image` 与普通聊天分流，`/image <description>` 是唯一进入图片链路的用户入口。
- 使用 LangGraph `StateGraph` 表达可审计的 ImageBrief/Prompt pass-revise-block 路径。
- 通过服务端固定 Provider、所有权校验和同源临时内容路由保障图片结果边界。
- 在现有 NDJSON 流和消息卡片中展示安全进度、ImageBrief、临时预览和下载。

## 用户可见能力

- 输入 `/image <description>` 进入图片生成链路，非显式请求仍是普通聊天。
- 生成过程中展示公开 ImageBrief、工作流阶段耗时和服务端总耗时。
- 完成后通过同源图片路由创建临时 Blob 预览和下载。
- 120 秒后仍保持处理中状态，直到存在明确终态。
- `/image` 使用独立每日配额：默认每浏览器 Session 3 次、每 IP 10 次（可配置 10–20）。无效、重放或 active-conflict 请求不消耗配额。

## 技术变更

- 固定使用 `doubao-seedream-5.0-lite` 与专属 Agent Plan endpoint，继续复用已有服务端 Doubao Key。
- `ImageGenerationRun` 为一次生成建立 active lease、幂等和临时结果元数据；Provider 调用前原子标记，确保最多一次外部生成。
- Image Agent Graph 限制五次规划调用、一次 Prompt 修正和一次生成，并在 strict structured parse 失败时安全终止。
- Stream 增加公开 `image-brief`、`image-result-ready` 与工作流阶段/总耗时。
- `POST /api/chat` 可创建 `StreamRun.kind = image_generation`。
- `GET /api/chat/runs/{runId}/image` 只向拥有该 run 的当前会话返回经过验证的临时图片字节。
- 新增 ADR-0016：Controlled Image Generation Agent。

## 非目标

- 不做编辑、局部重绘、扩图、去背景、参考图或多图。
- 不做 HITL、checkpoint/resume、开放式 ReAct 循环、自动重试或成本估算。
- 不做 OSS、对象存储、长期图片历史或刷新后的 Blob 恢复。
- 不修改 stream protocol public shape 中与图片无关的部分。

## 验证情况

- 覆盖命令解析、Provider 参数/错误、Graph 分支与上限、Repository 并发/过期、路由、reducer、UI、取消和临时内容安全。
- 覆盖超过 120 秒时保持生成中，以及安全阶段和服务端总耗时。
- 确定性测试、typecheck 和 lint 通过。
