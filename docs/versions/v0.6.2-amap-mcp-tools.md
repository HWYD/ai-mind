# AI Mind v0.6.2：AMap MCP Tools

v0.6.2 为普通 General ReAct 聊天增加九项固定的高德地图只读 Tool：POI 关键词、周边和详情搜索，地理与逆地理编码，以及步行、驾车、骑行和公交路线规划。

## 接入边界

- 高德托管 MCP 只通过固定 server-side endpoint 与 `amap-maps` server definition 接入；缺少服务端 Key 时九项 Tool 都不会绑定给模型。
- 模型只看见 AI Mind 定义的九项静态名称。真实 `tools/list` 用于兼容性核验，不能让远端新增 Tool 扩大模型权限。
- 地图调用与 `web-search` 对齐为 `remote-readonly + retrySafe: true`：Tool Runtime 对 timeout、连接、429、5xx 和 adapter 识别的短时频率限制在预算、deadline 与 retry permit 允许时最多再试两次；已通过 schema 但无法归类的只读 MCP `isError` 最多再试一次。schema/4xx、权限、已识别额度、空与 malformed 结果由模型以不同参数在下一 Action 修正，adapter 与 MCP client 不增加独立等待、重试或 session recovery。
- `amap-maps` 只在 MCP Client Manager 启用进程内共享的请求节奏控制：每批最多 3 条，整批结束后冷却 800ms。取消和关闭前尚未发送的队列项不会外发；这不改变 General ReAct 的全局并发或其他 MCP server，也不是账号级限流。800ms 是比已通过的 500ms smoke 更保守的用户配置。
- 坐标只接受 GCJ-02 `longitude,latitude`，最多六位小数。明确标注 WGS-84、GPS 或 BD-09 时会在 provider 前拒绝，不做隐式转换。

## 隐私与存储

地图 Tool 自己生成固定的 public input/output 摘要。`tool-start`、`tool-end`、tool error 及其 `StreamEvent` 副本不含 Key、带 Key 的 URL、原始 MCP 内容、原始 query、完整地址、坐标、路线详情或 POI 原始字段。

用户和模型都可生成 POI ID、坐标、城市、地址和路线端点等业务参数候选；它们须先通过 schema、GCJ-02/范围和出站安全校验，只有真实 observation 才能支持回答事实。缺少位置锚点时不假定当前位置。Memory、快照与 PostgreSQL 继续使用既有通用 Tool 策略，没有地图专用的存储分支。

## 验证

2026-09-27 的受控低频 smoke 已完成 `initialize`、`tools/list`、九项 contract call 和九项应用 adapter 调用。2026-09-28 的外部 smoke 进一步完成真实 POI 详情 3×3 批次调用；自动化验证覆盖固定绑定、schema、GCJ-02、模型/用户候选参数、安全 repair、超时与重试边界、批次取消/关闭、安全 Trace/StreamEvent、通用 Trace 展示以及普通 Tool 持久化投影。

后续维护移除了会拒绝模型补全参数的来源门禁，并将 Trace 展示为“地点搜索”“地址转坐标”“驾车路线规划”等具体用途；失败只显示固定安全类别。地图 Tool prompt 也补齐了九项用途、候选参数与事实边界。`deepseek-v4-pro` 在用户开启“深度思考”时会显式请求 reasoning，工具仍由模型在输入充分时自行选择。

AMap MCP 的 HTTP 状态、稳定失败类别与受限 retry 元数据会以不含原始文本的安全标量传给通用重试策略；adapter 仅在内存中归类 MCP `isError`。明确的瞬态失败最多重试两次，无法归类但已通过 schema 的只读失败最多重试一次。逆地理编码只保留国家、省、市、区；明确的空 POI 数组会显示为“未找到地点”，并阻止模型用相同参数循环查询。

提示词统一以当前 Run 工具结果作为即时、精确或外部事实的依据；结果缺失、失败或未完成时如实说明，不用模型常识、估算、同类候选或调用顺序补齐。地点、路线、附近地点和跨城公交场景只用于说明地图工具如何按用户问题选择调用。

受限收口但已生成最终回答的 General ReAct Run 显示“已完成思考”；`constrained` 继续仅用于 Runtime 预算、Trace 展开和 Memory 收口。最终收口模型也使用 Tool result facts rule；路线工具未返回距离或时长时，不会依据坐标或经验补写估算。

天气工具没有在本版本替换；现有 `city-weather` 的稳定性诊断保留给后续独立版本。
