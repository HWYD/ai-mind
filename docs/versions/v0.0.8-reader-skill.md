# v0.0.8 Reader Skill

## Summary

`v0.0.8` 新增第二个正式 Skill：`reader-skill`，并把版本主线收敛到外部上下文获取能力。

本版本新增两个 Tool：

- `city-weather`
- `local-text-read`

同时，前端进入正式组件基线统一阶段，接入 `shadcn/ui` 并切到 `radix-vega` 基线。

## Goals

- 新增 `reader-skill`。
- 支持实时天气查询。
- 支持项目根目录文本文件读取。
- 在自动模式下高置信命中天气和文件读取请求。
- 保持 `utility-skill` 和普通聊天不退化。
- 建立更统一的前端组件视图基线。

## Non-goals

- 不做 `writer-skill`。
- 不做网页抓取。
- 不做 MCP。
- 不做 Agent。
- 不做文件浏览器。
- 不做 slash command。
- 不做深色模式。

## Key Changes

### reader-skill

`reader-skill` 定位为外部上下文获取 Skill。

它优先处理：

- 城市实时天气查询。
- 项目根目录文本文件读取。
- 基于读取结果的简洁总结或提取。

它不处理通用写作、搜索、研究工作流或任意文件系统访问。

### city-weather

`city-weather` 用于查询指定城市的当前天气。

首版边界保持简单：

- 单参数 `city`。
- 当前天气。
- 不做复杂地理歧义处理。

### local-text-read

`local-text-read` 用于读取项目根目录直接文本文件。

安全边界：

- 只允许根目录直接文件。
- 不允许子目录。
- 不允许绝对路径。
- 不允许父级目录穿越。
- 只允许文本类文件。
- 超长内容截断。

### 自动 Skill 路由

路由顺序为：

1. 显式 `options.skill` 优先。
2. 未传 Skill 时走轻量规则路由。
3. 高置信实用请求命中 `utility-skill`。
4. 高置信天气或文件读取请求命中 `reader-skill`。
5. 未命中时回退普通聊天。

本版本强调宁可少命中，也不要乱命中。

### 前端组件基线

前端接入正式 `shadcn/ui` 基线。

Skill 模式统一为：

- 自动。
- 实用。
- 读取。

输入区、顶部错误条、推理面板、Tool 卡片、空状态等区域统一到同一套组件语言。

## Important Interface Changes

- Skill 模式支持 `自动 / 实用 / 读取`。
- 新增 `reader-skill` definition。
- 新增 `city-weather` Tool。
- 新增 `local-text-read` Tool。
- 自动路由开始区分实用类请求与读取类请求。
- 前端 UI 基线收敛到 `shadcn/ui` 与 `radix-vega`。

## Test Plan

- 验证显式 `reader-skill` 下天气请求能触发 `city-weather`。
- 验证显式 `reader-skill` 下文件读取请求能触发 `local-text-read`。
- 验证自动模式下高置信天气和文件读取请求能命中 `reader-skill`。
- 验证 `utility-skill` 不退化。
- 验证普通聊天未命中 Skill 时仍可直答。
- 验证模型选择器、深度思考开关、Skill 切换、推理面板和 Tool 卡片正常。

## Result / Outcome

`v0.0.8` 证明 Skill Runtime 可以承载模型本身不具备的实时信息和本地上下文获取能力。

项目在这一版中形成了更清晰的 Skill 分工：`utility-skill` 负责确定性实用任务，`reader-skill` 负责外部上下文获取。
