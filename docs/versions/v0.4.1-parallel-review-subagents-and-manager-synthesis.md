# AI Mind v0.4.1: Parallel Review Subagents + Manager Synthesis

## 摘要

v0.4.1 把 `/delivery-chain` 的 Review 阶段从单 subagent 串行升级为 3 个 review-class subagent 并行执行，并引入基于规则的 `synthesizeReviewBundle` 综合判断。

新的主链路是：

```text
/delivery-chain
  -> resolveDeliveryChainInvocation
  -> load demo context
  -> ControlledDeliveryManager
       -> phase: plan (串行)
            -> call plan-subagent tool
       -> phase: task (串行)
            -> call task-subagent tool
       -> phase: review-group (并行)
            -> call review-subagent tool with plan + tasks artifacts
            -> call risk-subagent tool with plan + tasks artifacts
            -> call boundary-subagent tool with plan + tasks artifacts
            -> receive 3 review results
       -> phase: synthesis
            -> construct ReviewBundle
            -> apply synthesis rules (blocked / conflict / merge)
            -> output Delivery Chain Report
  -> output final report
```

## 为什么需要这个版本

v0.4.0 建立了 `ControlledDeliveryManager` 的串行委派架构，但 Review 阶段只有一个 `review-subagent`，无法从多个维度（覆盖度、风险、边界）并行评审。

v0.4.1 的目标是：

- 在 Review 阶段引入 `risk-subagent` 和 `boundary-subagent`，与 `review-subagent` 并行执行。
- 通过 `ReviewBundle` 聚合三个评审结果，再用 `synthesizeReviewBundle` 做综合判断。
- 保持 v0.4.0 的受控边界：不修改全局 `allowParallel`、不新增 public command、不修改 stream chunk schema。

## 核心设计

### Phase-aware DelegationPolicy

- `DelegationPolicy.allowParallel` 保持 `false`（全局不放开并行）。
- 新增 `ReviewGroupPolicy`，只在 Review phase 内部允许并行。
- 新增 `validateToolCallBatchForPhase` 和 `validateReviewGroupToolCall`，区分串行和并行阶段的校验逻辑。

### ReviewBundle synthesis 规则

按优先级处理：

1. boundary blocked → final = blocked
2. risk severity = blocker → final = blocked
3. boundary failed → final ≥ needs_review
4. review failed → final = needs_review
5. risk high → report 包含 high risk section
6. risk failed → report 标注 risk missing
7. 相同问题合并
8. 冲突意见标注

### Partial failure 安全处理

- 1-2 个 review failed：标记 `failedReviews`，继续 synthesis。
- 3 个全 failed：fail closed，输出安全失败报告。

## 与 v0.4.0 的关系

| 维度              | v0.4.0                    | v0.4.1                               |
| ----------------- | ------------------------- | ------------------------------------ |
| Review subagent   | 1 个（review-subagent）   | 3 个（review + risk + boundary）     |
| Review 执行       | 串行                      | 并行（Promise.all）                  |
| DelegationPolicy  | 固定 allowParallel: false | phase-aware（Review Group 内部并行） |
| Report synthesis  | 模板拼接                  | 规则优先 + 结构化报告                |
| maxToolCalls      | 3                         | 5                                    |
| workflow progress | delegate-review           | delegate-review-group                |
