# AI Mind v0.4.4: Minimal Multi-thread Chat Sessions

v0.4.4 在 v0.4.2 单会话 memory baseline 和 v0.4.3 final-turn memory 基线上，把 chat page 扩展成“当前 browser session 下最多 10 个最近 persisted conversations”的最小多会话版本。

## 目标

- 支持从 sidebar / mobile drawer 进入一个新的 blank draft
- 支持 blank draft 在首条 user message 提交时转正为正式 conversation
- 支持在 recent conversations 间切换，只恢复当前 selected persisted conversation
- 让 messages、summary、pinnedDecisions、compaction、final-turn memory append 全部按 conversation 隔离
- 在 desktop / mobile 上提供最小可用的 conversation navigation UI

## 非目标

- 不做账号级历史记录、搜索、分页、重命名、删除、归档、分享、文件库、项目、应用入口
- 不引入 `ChatSession` / `ChatMessage` 业务表
- 不做 legacy `chat:${sessionHash}` 迁移兼容
- 不修改 stream protocol、frontend reducer public shape、Tasklist checkpoint/resume 语义或 Delivery run-local 语义

## 关键实现

- 引入 browser-session scoped Conversation Registry，按 `lastActiveAt` 排序并限制为 10 条 persisted conversations
- conversation ownership 通过 server-validated `conversationId` 落到独立 chat memory thread id
- chat page 初次进入若没有 persisted conversation，则进入 blank draft，而不是创建 default conversation
- client localStorage 只保存 persisted restore hint 和 draft sentinel，不直接决定服务端 memory ownership
- blank draft 不进入 recent list / registry；首条发送走显式 `createConversation: true` promotion path
- hydration 只跟随真实 persisted conversation 切换，不因同一会话的 stream status 变化而重复清空消息
- UI 优先复用本地 `shadcn/ui` / `radix-vega`，本版补齐本地 `sheet` primitive，不依赖 MCP 或 remote UI registry
