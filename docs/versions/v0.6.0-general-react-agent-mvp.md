# AI Mind v0.6.0：General ReAct Agent MVP

## Summary

v0.6.0 将普通 `routeType=chat` 统一交给受控 General ReAct Agent。模型可以在无需工具时直接回答，也可以在受控预算内并行调用固定的 `web-search`、`read-url`、`calculator`、`datetime`、`text-transform`、`unit-convert` 与 `city-weather`，再基于安全 observation 收口最终回答。Tasklist Agent、Delivery Chain 和 Image Agent 保持专用 runtime、权限和 presentation。

## Key Changes

- LangChain v1 `createAgent(version='v2')` 作为唯一 generic loop。
- Composer 显式上下文先做确定性准备，再进入同一 Agent；Skill 仅叠加可信提示词/输出风格，不授予 Tool、MCP 或隐式上下文权限。
- `web-search` / `read-url` 以 server-only `AI_MIND_WEB_PROVIDER` 静态选择 Tavily（默认）或智谱；智谱固定 Search-Std/Reader，缺少所选 key 或配置非法时 fail-closed，不做自动 provider 切换或 failover。
- 新增 `agent-run-start/end`→`agent-run` 的最小通用生命周期和单一 public-safe General ReAct Trace；专用 LangGraph 保留 `agent-graph-*`→`agent-graph`，完成态 Trace 和答案复用现有 IndexedDB snapshot。
- Dynamic MCP schema strict 校验，public input/output 不回退 raw payload，Tool Runtime signal 贯穿 SDK 且通用路径关闭 client 隐式 session retry。
- 固定 4 action rounds、9 logical Tool Calls、6 model calls、145s action cutoff、180s hard deadline、Tool concurrency 3、Run retry 4 和每进程 8 active Runs。
- PostgreSQL-first persist-before-publish、40ms/256-char server microbatch、64/256KiB backpressure 与 20ms+rAF browser buffering。
- calculator 增加允许语法、标识符、括号深度、token/operator 数量边界，避免同步 CPU 无界执行。

## Non-goals

不新增 Redis、Worker Thread、Agent checkpoint、AgentRun、StreamRun kind、IndexedDB store、Prisma migration 或通用 Agent Tool；不展示 raw reasoning、网页正文、provider error 或凭据。
