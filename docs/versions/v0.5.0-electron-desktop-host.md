# AI Mind v0.5.0：Electron Desktop Host

## 概述

v0.5.0 为既有在线 AI Mind Web 应用增加 Windows x64 与 macOS arm64 的 Electron 桌面宿主。
桌面端不是第二套 AI Runtime：聊天、图像、受控 Agent、会话和可恢复流式任务仍由 Web 应用与服务端负责。

## 本版设计

- 打包版本使用固定的生产 HTTPS Origin；开发模式仅接受显式的 localhost Origin。
- 加载工作区前先通过 compatibility gate；一次启动、重试或重置共享 5 秒时限，失败时 fail closed 到包内恢复页。
- 远程工作区没有 preload、Node integration 或通用 IPC bridge。
- 工作区使用当前操作系统用户下的持久 profile；恢复页使用隔离的内存 session；服务端会话 cookie 采用 30 天滑动续期。
- 导航、弹窗、权限、剪贴板读取、外部打开和下载默认拒绝；只有受信页面的用户主动图像保存可进入原生保存对话框。
- 为 Electron fuses、Windows x64 与原生 macOS arm64 打包、严格 compatibility API 以及 Web 应用 nonce CSP/security headers 提供验证覆盖。

## 发布边界

`v0.5.0-public-beta` 已作为公开 GitHub Pre-release 提供未签名的 `Unsigned Experimental Preview`：<https://github.com/HWYD/ai-mind/releases/tag/v0.5.0-public-beta>。它不包含正式代码签名、自动更新、离线 Runtime、可编辑 Origin、诊断上传或通用本机文件 API。

发布策略仍要求线上 compatibility API 与 document headers 的生产验证，并对同一 source commit 的安装器、manifest 与 SHA-256 进行核验。发布后还必须完成 Windows x64 与 macOS arm64 的 fresh install、overlay install 和安全拒绝场景的手工验收。

## 当前验收状态

公开 Pre-release 于 2026-08-08 发布，目标 commit 为 `a39dc9f4f7424dbf787a3df6219a93a069b82326`，包含 Windows x64 安装器、macOS arm64 DMG、平台 manifest、SHA-256、安装说明和 README，共 9 个 assets。当前仍未在验收台账中记录 production verifier、双平台 fresh install / overlay install smoke 和最终角色 sign-off；因此 v0.5.0 的公开预览可下载，但 release closing 尚未验收通过。
