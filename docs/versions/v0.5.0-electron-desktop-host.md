# AI Mind v0.5.0：Electron Desktop Host

## 概述

v0.5.0 为现有在线 AI Mind Web 应用增加 Windows x64 与 macOS arm64 Electron 宿主。聊天、图像、Agent、会话和 Stream recovery 仍由 Web 应用与服务端负责，桌面进程只负责固定 Origin 准入、隔离 profile、本地 recovery 和受限原生能力。

## 公开试用定义

本版本以 GitHub Pre-release 形式提供 `Unsigned Experimental Preview`。制品未进行 Authenticode、Developer ID 或 notarization，在线运行且无 auto-update。公开资产必须包含安装包、manifest、SHA-256 和 SmartScreen/Gatekeeper 安装说明。

## 支持范围

- Windows x64 Squirrel 安装包
- Apple Silicon macOS arm64 DMG
- 不支持 Windows ARM64、macOS Intel/universal、Linux 和离线 Runtime

## 发布前置

维护者先通过现有部署路径发布候选 commit，并运行生产 compatibility/header verifier；通过后手动触发 public beta Workflow。Agent 不执行生产部署、不读取生产 secret，也不自动合并。
