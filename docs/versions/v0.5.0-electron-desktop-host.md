# AI Mind v0.5.0：Electron Desktop Host

## 概述

v0.5.0 为既有在线 AI Mind Web 应用增加 Windows x64 与 macOS arm64 的 Electron 桌面宿主。
桌面端不是第二套 AI Runtime：聊天、图像、受控 Agent、会话和可恢复流式任务仍由 Web 应用与服务端负责。

## 本版设计

- 打包版本使用固定的生产 HTTPS Origin；开发模式仅接受显式的 localhost Origin。
- 加载工作区前先通过 compatibility gate；一次启动、重试或重置共享 5 秒时限，失败时 fail closed 到包内恢复页。
- 远程工作区没有 preload、Node integration 或通用 IPC bridge。
- 工作区使用当前操作系统用户下的持久 profile；恢复页使用隔离的内存 session；服务端会话 cookie 采用 30 天滑动续期。
- 导航、弹窗、权限、剪贴板读取、外部打开和下载默认拒绝；只有受信页面的用户主动图像保存可进入原生保存对话框。
- 为 Electron fuses、Windows x64 与原生 macOS arm64 打包、严格 compatibility API 以及 Web 应用 nonce CSP/security headers 提供验证覆盖。

## 发布边界

本版目标是公开 GitHub Pre-release 中未签名的 `Unsigned Experimental Preview`。它不包含正式代码签名、自动更新、离线 Runtime、可编辑 Origin、诊断上传或通用本机文件 API。

创建公开 GitHub Pre-release 前，必须先完成线上 compatibility API 与 document headers 的生产验证；之后还需要对同一 source commit 的安装器、manifest 与 SHA-256 进行核验。

## 当前验收状态

此前 v0.5.0 代码已经合并到 `main` 并部署线上；本工作区新增的 `public-beta` metadata 与公开发布 Workflow 仍待合并和部署。其后必须为同一候选版本运行生产 verifier，并收集 Windows/macOS 的 fresh install 与 overlay install smoke 证据，才可手动创建 GitHub Pre-release。
