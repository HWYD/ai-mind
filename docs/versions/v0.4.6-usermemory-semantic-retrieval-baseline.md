# AI Mind v0.4.6: UserMemory Semantic Retrieval Baseline

## Summary

v0.4.6 在 v0.4.5 的 browser-session scoped `UserMemory Store` 基线上增加 semantic retrieval。对于仍在 ordinary chat boundary 内的请求，runtime 可以用当前最新用户输入检索同一 browser session 的相关长期 UserMemory，并作为有边界的补充上下文参与回答。

## Goals

- 支持不依赖完全关键词重合的长期偏好与稳定约束召回。
- 将真实 semantic retrieval 保持在 `PostgresStore`、UserMemory validation 与 chat runtime 的既有边界内。
- 在检索失败时保持 ordinary chat、streaming、ThreadState 与 final-turn memory 正常工作。
- 继续保护公共 DTO、stream protocol 和 Agent / Workflow 边界。

## Non-goals

- 不做 RAG、文档问答、聊天历史语义搜索或完整 transcript 向量化。
- 不做 account-level memory、跨设备同步、Memory Inspector、记忆编辑/删除 UI 或批量 re-embedding 后台。
- 不新增 UserMemory 写入来源，也不把每一轮 assistant 回复自动提升为长期记忆。
- 不使用独立向量数据库、`PostgresStore` hybrid/text search、rule-based 或 lexical fallback。

## Key Changes

- 正式 retrieval path 固定为 `PostgresStore` vector search，初始 `topK = 8`，最终注入要求 semantic score `>= 0.32`。
- semantic index 只允许 validated `UserMemory.text` 与 `UserMemory.tags`；内部 metadata 记录索引版本、字段和 embedding 标识，但不保存 raw vector 或敏感运行时数据。
- embedding 使用独立 UserMemory runtime config，固定走火山引擎 Ark OpenAI-compatible `doubao-embedding-vision`，不跟随聊天模型选择器。
- retrieval query 直接使用 latest user input，仅做 trim、空白折叠与 800 字符裁剪；不执行 LLM query rewrite、HyDE 或 query expansion。
- active、confidence、suppression、semantic score、`stableKey`、conflict 和 context budget 在注入前统一过滤；最多选择 3 条，每条最多 300 字符，总计最多 900 字符。
- provider、Store、timeout 或 score 异常统一降级为 0 条注入，并以脱敏事件日志记录，不影响普通聊天主流程。

## Important Interface Changes

本版没有新增公开 API、stream chunk、hydration payload 或 frontend reducer 字段。`UserMemory`、embedding vector、semantic score、query 和原始 provider/store 错误都保持在服务端内部。

真实本地 semantic retrieval 需要 `DATABASE_URL`、Store setup、`AI_MIND_DOUBAO_API_KEY` 与 `AI_MIND_USER_MEMORY_EMBEDDING_DIMENSIONS`。embedding dimensions 按 `doubao-embedding-vision` 的当前官方规格配置，不在版本文档中固定。

## Test Plan

- 覆盖跨 conversation 的回答风格与饮食偏好语义召回、无关问题 0 注入、suppressed/inactive 排除、当前输入冲突优先级与 context budget。
- 覆盖 vector-only search、allowlist index、query 规范化、1500ms timeout、embedding/Store failure 和异常 score 的安全降级。
- 覆盖 ordinary/tool-assisted chat 接入，以及 Tasklist、Delivery、HITL、hydration、Conversation Registry、stream-core 和 reducer 非回归。
- 执行 focused runtime suites、`pnpm --filter @ai-mind/stream-core test`、`pnpm --dir apps/webapp test`、`pnpm typecheck`、`pnpm lint:webapp` 与 `git diff --check`。

## Result

v0.4.6 完成了 UserMemory vector semantic retrieval baseline。长期记忆仍然只是当前 browser session 内的受控补充上下文：selected conversation 的 `ThreadState` 继续是短期事实源，Tasklist / Delivery 与公开协议边界保持不变。
