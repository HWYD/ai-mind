# AI Mind v0.2.3：Tasklist Agent Graph Runtime Consolidation

## Summary

v0.2.3 是一次架构收口版本，不新增 Agent 能力。  
本版将 `/tasklist + @docs://versions/*.md` 的 Tasklist Agent 从 legacy runner + Graph Runtime 双路线收口为 Graph Runtime 单一路线，删除迁移期 runtime switch / fallback，并整理 GraphState、node、route、stream、debug 和测试结构。

## Goals

- `/tasklist + @docs://versions/*.md` 只走 Graph Runtime。
- legacy runner 不再从生产路径可达。
- 历史 `AI_MIND_TASKLIST_AGENT_RUNTIME` 不再参与运行配置或执行路径判断。
- GraphState 成为 Tasklist Agent 内部唯一运行态。
- Graph nodes 返回明确分区 patch。
- Graph routes 基于显式 state 字段判断。
- 保持 tasklist artifact、stream chunk 和 AgentTracePanel 兼容。
- Graph Debug Summary 继续只输出脱敏摘要。

## Key Changes

### Graph-only Runtime

Tasklist Agent 入口现在直接调用 Graph Runtime：

```text
/tasklist + @docs://versions/*.md
  -> ChatOrchestrator
  -> runVersionPlanTasklistGraph()
```

历史 legacy runner、legacy wrapper 和 runtime selector 已删除。

### GraphState Consolidation

GraphState 不再以外层 `agentState` 包装作为长期事实源，而是按 Graph Runtime 需要分区承载运行态：

- `input`
- `source`
- `planning`
- `tasklist`
- `execution`
- `output`
- `graph`

领域类型仍保持原命名，例如 `PlanReadinessResult`、`PlanningDecisionAction`、`TasklistStrategy`、`WarningDisposition`、`RevisionEffectResult`。

### Compatibility

本版保持以下外部协议稳定：

- `/tasklist` 入口
- tasklist markdown artifact
- `artifact-start` / `artifact-delta` / `artifact-end`
- graph events
- Graph Debug Summary
- AgentTracePanel 消费结构

### Runtime Config

- `AI_MIND_TASKLIST_AGENT_RUNTIME` 不再参与 Tasklist Agent 执行路径判断。
- `AI_MIND_GRAPH_EVENTS`、`AI_MIND_GRAPH_DEBUG_VIEW`、`AI_MIND_GRAPH_CHECKPOINT` 继续保留。
- `AI_MIND_GRAPH_CHECKPOINT` 由显式 env 控制，可在 development 或 production 下开启，但不表示持久化、Resume 或产品级恢复能力。

## Non-goals

本版不做：

- HITL
- Durable Agent Run
- Resume API
- Run History
- AgentRun 数据库持久化
- Redis / usage counter
- 新 Agent 类型
- 自由 tool calling
- 前端 UI 重做
- Model Provider Runtime 改造
