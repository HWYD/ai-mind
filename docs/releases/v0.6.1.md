# v0.6.1 发布收口记录：General ReAct Agent Streaming

**状态**：2026-09-23 发现 pre-execution ToolCall Trace truth gap 后曾重新打开 release gate；修复的自动化、真实环境浏览器验收和本机 integration 证据均已记录，用户于 2026-09-24 接受 AC-039 本地 release closing。六个 manifest 已重新核对为 `0.6.1`。本地收口不等于已创建外部发布：尚未创建 Git tag、GitHub Release，亦未推送、提交或合并。

## Summary

本版移除了普通 General ReAct 成功路径中的固定第二次 Answer 调用。无 Tool 的自然完成正文可在原模型轮次直接流式成为 final answer；带 Tool 的模型可公开说明作为 commentary 与执行 Trace 同步展示。

## Completed

- 增加 `agent-text-*` public stream contract、严格 schema、reducer 与 durable replay 支持。
- 以 `pending/commentary/final_answer` 组织 General Agent 正文，最终正文与过程说明不再混用普通 TextPart。
- 将正文说明、Tool、Skill、Resource、Prompt 组合为按事件顺序的 flat Trace；`web-search` 只显示本次调用自身安全 `discovered` 来源数，安全 read source 紧随所属 Tool，不在 Trace 尾部汇总；所有 Agent 正文使用同一 Markdown、无文本图标，Tool 不含 nested detail。
- 将 normal/constrained 收口 provenance 贯穿 Run end、UI、same-session history、Memory 和本地 snapshot。
- 按选择性约 1.5 倍策略提升 General Agent 预算，并保持 Tool concurrency、retry 与 timeout profile。
- 补齐 provider 前拒绝的模型 ToolCall 的可审计失败 Trace，并让 direct-final loop/finalizer 共享当前 Run observation 的事实边界。
- 当前用户 URL 自动受现有安全策略保护；受限同会话 raw-user URL 复用不再依赖客户端 history，且不冒充历史 Tool 执行证据。

## Technical Highlights

- `createAgent(version='v2')` 继续拥有动态 Tool loop；没有引入第二套手写 ReAct/Chain 控制面。
- provider 明确的 `length/error` 进入受限收口判定；content filter 和未知显式终止状态 fail closed。
- 首个 Agent text delta 立即 durable flush，后续保留 40ms/256-char batching；commentary end 在 Tool start 前提交。
- 最终回答选择器只消费 completed `final_answer`，从而保护 copy、feedback、follow-up、Memory 与 snapshot 边界。

## Known Limits

- constrained finalizer 的成功正文不会写入 Chat Memory 或 UserMemory。
- Tool 级详情、raw Tool payload、reasoning 展示和 server-side Trace storage 不在本版范围。
- 数据库集成测试已在本地 pgvector PostgreSQL 环境通过；真实调用页面与 Pencil 已确认 no-Tool 直出、含 Tool 的流序/来源子项和公开行动说明；用户确认 disclosure 手动展开与刷新默认收起，keyboard/ARIA 由自动化合约覆盖。2026-09-24 的真实环境复验也确认当前 URL 自动读取、明确重读 URL 与 rejected-Tool/URL-provenance 场景。
- Phase 10 后的本机 integration 重验中，database 5 项与 webapp 31 项均通过。desktop Playwright 有 14 项通过、6 项受 Electron GPU process host 崩溃及临时 Local Storage 清理锁定影响；用户确认真实环境测试完成，并接受该宿主限制不作为 AC-039 阻塞项。它仍是后续桌面自动化环境应处理的风险，不回写为功能通过。
- closing 期间有一次未改动 calculator 的 CPU 时间断言在共享负载下超过阈值；隔离重跑与 fresh 全量 stable 重跑均通过，CI 应持续观察该时序风险。
