# v0.3.0 Release Note

## Summary

v0.3.0 为 Tasklist Agent 增加 HITL Checkpoint Resume MVP：策略必审、需要修订时人工授权、最多两轮受控修订，并用 PostgreSQL 持久化 AgentRun 与 LangGraph checkpoint。

## Completed

- Strategy Review 必停，支持 approve / edit / reject / respond。
- Strategy edit 使用结构化表单字段。
- Tasklist Revision Review 仅在 `fixNow` 非空时触发。
- Revision Review 是修订前授权，不是草稿每次必停。
- resume 继续更新原 assistant message。
- pending HITL 时锁定普通 Composer。
- 刷新后不恢复 pending HITL。
- 新增 Prisma / PostgreSQL 数据层。
- 新增 AgentRun / AgentInterrupt。
- 接入 LangGraph Postgres checkpointer。
- 本地、CI、生产部署链路具备数据库初始化步骤。

## Known Limits

- HITL 只作用于 `/tasklist + @docs://versions/*.md`。
- 不支持普通聊天、Skill、Tool Calling、MCP 审批。
- 不支持 Run History、Trace replay 或跨版本 checkpoint resume。
- 浏览器级 HITL smoke 需要人工复验。
