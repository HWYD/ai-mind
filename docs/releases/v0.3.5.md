# v0.3.5 Release Note

## 摘要

v0.3.5 是 `Agent Demo Workspace Resource Boundary`。
本版将 public demo 的 Agent 可读资源收口到 `examples/agent-demo/`，新增 `@demo://` scheme，并让 `/tasklist` public demo 入口迁移到 `@demo://version-plans/*.md`。

## 已完成

- 新增 `specs/035-agent-demo-workspace-resource-boundary/` 完整规格资产。
- 新增 ADR-0009，固化 public agent demo resource boundary。
- 新增 `examples/agent-demo/` demo workspace 和 `demo-manifest.json`。
- 新增 `@demo://` resolver，限制 public demo 资源只能来自 `examples/agent-demo/`。
- `@docs://` 在 public demo 中 fail closed，并返回清晰边界提示。
- `/tasklist` public demo 入口迁移到 `@demo://version-plans/*.md`。
- `@` resource picker 只展示 demo version-plans。
- 快速访问新增 Tasklist Agent demo，默认使用 `v034-langsmith-observability.md`。
- 小屏移动端对 composer、模型选择器、slash/resource popup 做最小密度优化。
- 更新 README、architecture docs、public version/release/tasklist 和 package version 到 `0.3.5`。

## 已知边界

- 本版只收口 public demo 资源边界，不扩展 Agent 权限。
- 不新增 `/plan`、`/task`、`/review`、`/delivery-chain`。
- 不新增 `@artifact://`。
- 不修改 Graph topology、HITL contract、stream protocol、frontend reducer、Prisma schema、PostgresSaver schema。
- 不改变 v0.3.4 LangSmith observer 语义。
- 不让 public demo 读取真实 `docs/`、`specs/`、`apps/`、`packages/`、`.env*` 或绝对路径。
