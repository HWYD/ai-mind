# v0.2.2 Release Note

## Summary

v0.2.2 完成了 AI Mind 的双应用容器化生产部署资产收口，并把真实腾讯云上线结果固化回仓库。当前生产拓扑已经验证“宿主机 Nginx + Docker Compose + 内网 PAS”的边界可行，GitHub Actions 到 TCR 的自动发布链路也已经补齐基础 workflow。

## Completed

- 新增生产 Compose，使用 registry SHA 不可变镜像运行 `webapp` 与 `project-assistant-service`。
- 新增生产 env example，明确模型 API Key、MCP Token、SSL 私钥不进入仓库与 GitHub Actions。
- 新增宿主机 Nginx 生产模板，保留 `/api/chat` 流式代理能力，并阻断公网 `/mcp`。
- 新增生产部署脚本与验收脚本，覆盖 `.release.env`、健康检查、HTTPS、HTTP 跳转和 PAS 不暴露。
- 将 release workflow 从 GHCR 改为腾讯云 TCR，并补齐 SSH 远端部署流程。
- 将真实生产偏差、镜像路径、Token 约束和证书路线同步回版本 plan / tasklist。

## Changed

- 生产镜像仓库从 GHCR 调整为腾讯云 TCR。
- HTTPS 证书策略从 Certbot-only 调整为宿主机证书管理，当前实际使用腾讯云 SSL 证书。
- `PROJECT_ASSISTANT_SERVICE_MCP_TOKEN` 从“建议配置”提升为生产 fail-closed 必填项。

## Verification

- 已验证 `project-assistant-service` healthy，且只 `expose 8788`。
- 已验证 `webapp` healthy，且只绑定 `127.0.0.1:3000 -> 3000`。
- 已验证 `https://ai.hwyblog.cloud` 正常访问。
- 已验证 `http://ai.hwyblog.cloud` `301` 跳转到 HTTPS。
- 已验证 `https://ai.hwyblog.cloud/mcp` 返回 `404`。

## Known Limits

- GitHub Actions 自动构建、推送 TCR、SSH 远端部署尚未以真实 production Secrets 跑通，因此本版不把“自动部署”记为完成。
- 证书续期仍由宿主机负责；替换证书文件后需要人工 reload Nginx。
- 更完整的业务 smoke、回滚演练和资源占用记录仍待补齐。

## Next

- 跑通首次 GitHub Actions 生产发布。
- 补齐回滚演练与生产 smoke 证据。
- 完善证书续期与宿主机运维文档。
