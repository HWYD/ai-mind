# v0.6.0 发布记录

**状态**：实现与仓库验收完成；真实 Tavily smoke 是否执行以 acceptance evidence 为准。

## Summary

普通聊天现在使用一个受控 General ReAct loop。它统一了直接回答、只读 Web、计算、时间、Skill/MCP context 和安全最终收口，同时不改变 Tasklist、Delivery Chain、Image Agent 的专用边界。

## Runtime And Safety

- `createAgent(version='v2')` 是 generic loop；state 只存在当前 Run。
- Tool、模型、观察、retry、action round 和 deadline 都有硬预算，schema/security/permission/cancel 失败不会 retry。
- Delivery subagent 明确为 `agent-tool/delegated-agent`，不套普通 Tool timeout/retry。
- public stream、Trace、Memory 和 local snapshot 均使用 allowlist，不包含 raw reasoning、原始 Tool 数据、网页正文、内部 prompt、provider error 或 secret。
- General ReAct 使用 `agent-run-start/end` 与 `AgentRunPart`；Tasklist 等专用 LangGraph Agent 保留 `agent-graph-*` 与 `AgentGraphPart`，不按 `agentName` 猜测 UI。
- Dynamic MCP schema strict 校验，public 摘要不回退 raw data，通用路径传播取消并关闭 MCP client session recovery 隐式 retry。

## Stream And Performance

StreamEvent 使用 PostgreSQL-first persist-before-publish。首个 final text delta 立即 durable flush，后续同 part 按 40ms/256 chars 合并；projection queue 64 items/256KiB 高水位、32/128KiB 低水位，当前 transport disconnect 不会取消后台 Run。每进程最多 8 个 generic Run，数据库 pool max 10。
