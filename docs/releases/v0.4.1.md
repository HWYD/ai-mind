# v0.4.1 Release Note

## 摘要

v0.4.1 是 `Parallel Review Subagents + Manager Synthesis`。

本版在 v0.4.0 的 `ControlledDeliveryManager` 基础上，将 Review 阶段从单 subagent 串行升级为 3 个 review-class subagent 并行执行，并引入基于规则的 `synthesizeReviewBundle` 综合判断。

## 已完成

- 新增 `risk-subagent` 和 `boundary-subagent` 两个 review-class tool，与 `review-subagent` 并列。
- 新增 phase-aware `DelegationPolicy`，支持 Review Group 内并行 tool calls，全局 `allowParallel` 保持 `false`。
- 改造 `ControlledDeliveryManager` 主循环为 phase 结构：plan(串行) -> task(串行) -> review-group(并行) -> synthesis。
- 新增 `ReviewBundle` run-local 内部结构，聚合三个评审结果。
- 新增 `synthesizeReviewBundle` 函数，实现 7 条 synthesis 规则（blocked 判断、冲突合并、风险排序、缺失检查等）。
- 新增 `delegate-review-group` workflow progress step，汇总并行评审进度。
- 扩展 `createSubagentResultArtifacts`，risk/boundary 产出 `kind: 'review'` + `metadata.reviewType`。
- Partial failure 安全处理：1-2 个 review failed 时 synthesis 继续，3 个全 failed 时 fail closed。
- `maxToolCalls` 从 3 调整为 5（plan + task + 3 review）。

## 已知边界

- 仍然只有 `/delivery-chain` 一个 Delivery Chain public command。
- 不新增 `/plan`、`/task`、`/review`。
- 不新增 `@artifact://`、artifact persistence、chat persistence、DB schema 或 Prisma migration。
- 不实现 free supervisor、dynamic routing、nested subagents、HITL-aware delegation。
- RuntimeArtifact 只在 run-local runtime 内部流转，不进入 `artifact-*` stream chunks 或 frontend `message.artifacts`。
- `ReviewBundle` 不进入 public DTO，不进入 DB / stream / frontend message。
- 不新增 stream chunk 类型，不修改 frontend reducer public shape。
- LLM 润色暂未实现（当前使用规则生成的报告），降级路径已预留。
