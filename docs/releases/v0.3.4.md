# v0.3.4 Release Note

## 摘要

v0.3.4 是 Tasklist Agent LangSmith Observability Integration。

本版在不改变 Tasklist Agent Graph、HITL 合约、数据库 schema、stream protocol 和前端 reducer 的前提下，为 `/tasklist + @docs://versions/*.md` 的 HITL checkpoint resume 链路增加可选 LangSmith lifecycle tracing。

LangSmith 只作为外部观测层，用来帮助定位 initial run、HITL interrupt、human decision、resume、final / blocked / rejected / failed 等关键状态；它不是 AgentRun / AgentInterrupt / checkpoint 的事实源。

## 已完成

- 新增 `specs/034-tasklist-agent-langsmith-observability/`，覆盖 spec、plan、tasks、acceptance、decisions、research、data-model、quickstart 和 contract。
- 新增 ADR-0008，记录 LangSmith observability boundary。
- 新增 Tasklist Agent observability 模块：
    - LangSmith config resolver。
    - metadata allowlist builder。
    - HITL metadata 提取。
    - result metadata 提取。
    - LangSmith observer adapter。
    - disabled no-op observer。
- `apps/webapp` 显式声明 `langsmith` direct dependency，避免依赖 transitive dependency。
- Tasklist Agent initial run 记录安全 metadata：
    - `runId`
    - `threadId`
    - `assistantMessageId`
    - `agentVersion`
    - `graphVersion`
    - `versionPlanUri`
    - `modelId`
    - `provider`
    - `reasoningEnabled`
    - `environment`
- HITL interrupt / human decision / resume 记录摘要 metadata：
    - interrupt kind / id
    - decision type
    - review round
    - strategy regeneration count
    - draft revision
    - validation finding counts
- final / blocked / rejected / failed 记录 result metadata：
    - run status
    - result status
    - artifact generated
    - duration
    - failure code
    - sanitized failure message
- LangSmith SDK 调用统一 soft fail，不影响 Tasklist Agent 主流程。
- 更新本地与生产 env 模板，新增最小 LangSmith 配置说明。
- 更新 README 和公开 docs，说明 LangSmith 只用于 Tasklist Agent observability，不是业务事实源。
- package version 更新到 `0.3.4`。

## 配置说明

本版只使用 LangSmith 官方 env：

```env
LANGSMITH_TRACING=false
LANGSMITH_API_KEY=
LANGSMITH_PROJECT=ai-mind-dev
```

生产环境建议使用：

```env
LANGSMITH_TRACING=false
LANGSMITH_API_KEY=
LANGSMITH_PROJECT=ai-mind-production
```

启用条件为：

```text
LANGSMITH_TRACING === "true" && LANGSMITH_API_KEY 存在
```

`LANGSMITH_TRACING=false`、API key 缺失或 LangSmith 上报失败时，Tasklist Agent 应继续正常运行。
