# v0.1.1 Release Note

## Summary

`v0.1.1` 将 `Version Plan to Tasklist Agent` 升级为 `Controlled Planner Lite`。

Agent 仍然只通过 `/tasklist + @docs://versions/*.md` 启动，但可以在 Runtime 白名单 action 中做一次有限决策，并通过 Agent Text Artifact 展示最终 tasklist 产物。

## Completed

- 新增 rule-based `PlanReadinessResult`。
- 新增 5 类 `PlanningDecisionAction`。
- 新增 optional context 白名单读取。
- 新增 `TasklistStrategy`，并接入 draft prompt。
- 新增 `WarningDisposition`，区分自动修正和人工复核点。
- 新增稳定 weak issue code。
- 新增 `RevisionEffectResult`，评估 v1 -> v2 的修正效果。
- `maxSteps` 从 8 调整为 12。
- `AgentTracePanel` 新增 decision / strategy / disposition / revision effect 摘要展示。
- 新增通用 Agent Text Artifact 协议，用于展示最终 tasklist Markdown 产物。
- 新增 `AgentTextArtifactPanel`，让最终 tasklist 正文独立于普通 assistant text 展示。

## Changed

- `validate_tasklist_structure` 的 warning 不再全部触发自动修正。
- optional context 失败时降级继续，不中断 Agent。
- `ask_clarification` 和 `stop_with_boundary_message` 进入 `stopped`，不走 final answer。
- tasklist draft prompt 会消费 `TasklistStrategy`。
- final answer text 不再承载完整 tasklist 正文，只保留结构校验、修正效果和人工复核点摘要。

## Technical Highlights

- Planning Decision 只开放 action 选择，不开放资源权限、工具权限、写入权限或循环权限。
- Plan readiness、warning disposition、revision effect 都由规则完成。
- 模型只负责 action 选择、strategy 生成、tasklist 草稿和一次修正。
- `read_optional_context` 最多读取一个白名单资源，不扫描 docs。
- AgentTracePanel 只展示摘要，不展开完整 JSON、prompt 或 AgentState。
- Agent Text Artifact 是 delivery streaming，不要求模型 token streaming；它按 Markdown 结构分段输出最终产物。

## Known Limits

- 本版仍然不是通用 Agent Runtime。
- 本版不接 LangGraph。
- 本版不做多 Agent。
- 本版不做 Human-in-the-loop 按钮审批。
- 本版不做 pause / resume / checkpoint。
- 本版不写入 docs 文件。
- 本版不读取历史 tasklist。
- 本版不自动扫描 `docs/versions/*`。
- 本版不从裸目标生成 tasklist。
- 本版不生成 v3。
- 本版不做 artifact 持久化、编辑、下载或 diff。
