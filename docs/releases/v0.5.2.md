# v0.5.2 发布记录

**状态**：发布候选；workspace package version 已锁步更新为 `0.5.2`。本地 CI 等价验证及真实历史的常规/4 倍 CPU 视觉验收均已完成；远端 GitHub Actions 通过是创建 tag 与 GitHub Release 的最终闸门。

## Summary

v0.5.2 改善历史聊天会话的进入与切换体验：最新消息在首次真实展示前已定位到可见区域，消息滚动条覆盖完整聊天列高度，悬浮输入框不再导致内容列偏移或遮挡。

## Completed

- 历史会话使用隐藏布局、`useLayoutEffect` 与可取消 rAF 校正，实现无可感知“顶部 → 底部”跳变的首次揭示。
- 消息区成为唯一全高滚动容器；Composer 使用底部浮层、渐变遮罩及真实动态安全区。
- 原生 scrollbar gutter 稳定预留，Composer 与消息内容列按实测滚动条宽度保持左右对齐。
- 本地会话切换不等待 selected-preference POST；本地快照、只读缓存、失败重试与快速 A→B 保持正确会话归属。
- 推荐问题与最新回复同一轮揭示，暂不可操作时仅禁用，不再延后插入造成二次重排。

## Known Limits

- 不包含尾页 cursor 分页、向上加载、虚拟列表、阅读位置或未读状态。
- 长历史、4 倍 CPU 与断网缓存的最终体验仍以本版 quickstart 手工验收和远端 CI 为发布依据。
- 本版本不发布新的桌面安装包，也不修改生产部署、API、数据库或 Electron IPC。

## Verification

已通过 `pnpm install --frozen-lockfile`、root stable/integration 测试、lint、typecheck、build 和 `git diff --check`。常规桌面/移动端与 4 倍 CPU 降速下的真实历史切换、刷新恢复、阅读位置保持、稳定 gutter 与推荐问题首帧均已记录到版本验收账本；最终远端状态以 main 分支 GitHub Actions 为准。
