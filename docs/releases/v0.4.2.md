# v0.4.2 Release Note

## 摘要

v0.4.2 是 `LangGraph Single Thread Memory Baseline`。

本版为当前唯一普通聊天会话引入可恢复的 thread memory：刷新后可以恢复 recent text messages，并通过 summary compaction 和 pinned decisions 控制普通 chat 的上下文大小。

## 已完成

- 新增普通 chat memory runtime boundary，包含 runtime config、thread id、ThreadState schema、message adapter 和 hydration DTO。
- 新增 chat memory checkpoint provider，支持 `AI_MIND_CHAT_MEMORY_CHECKPOINT=off|memory|postgres`。
- 新增独立 checkpoint schema：`langgraph_chat_memory`，并接入 `pnpm db:setup:deploy`。
- 新增 `GET /api/chat/thread`，提供严格安全的 hydrate DTO。
- 普通 chat、reader/utility、docs-summary text path 以后端 ThreadState 作为历史事实源读取 memory context，只从前端 payload 取本轮最新 user input，并在 completed assistant turn 后一次性写入 memory。
- 新增以完整对话轮次为阈值的 recent context compaction、summary、pinned decisions 和 compaction failure no-op 策略。
- 新增可选 `thread-memory-status` stream chunk，用于在输入框上方展示普通 chat memory 的压缩开始/成功/失败弱提示。
- 明确排除 `/tasklist`、`/delivery-chain`、tool transcript、MCP transcript、Tasklist GraphState、HITL state、Delivery RuntimeArtifact 和 raw runtime internals。
- 保持 Tasklist Agent checkpoint / resume、Delivery Chain run-local artifact、`delivery-chain-manager` transcript suppression 和 stream-core chunk union 不变。

## 已知边界

- 当前只支持单浏览器单会话 chat memory，不做多会话历史列表。
- 不新增 ChatSession / ChatMessage Prisma 业务表。
- 不做长期记忆、pgvector、LangGraph Store 或 Memory Inspector。
- hydrate 只返回安全 DTO，不暴露 raw checkpoint、raw prompt、provider response、stack、GraphState 或 RuntimeArtifact。
- 普通 chat 前端请求仍保留最近 8 轮本地 turns；服务端额外补充 bounded memory context。
