# v0.0.5 Release Note

## Summary

`v0.0.5` 在本地聊天链路上新增最小 Tool Calling 闭环，让模型可以发起工具调用，服务端可以校验并执行工具，前端可以结构化展示结果。

## Completed

- 新增单个 Tool：`calculator`。
- 支持模型返回 `tool_calls`。
- 支持工具参数归一化与 `Zod` 校验。
- 支持 ToolMessage 回填后生成最终答案。
- 前端支持 `reasoning / tool / text` 三类 part。
- 为后续多 Tool Registry 预留结构。

## Changed

- 服务端从纯模型问答升级为可选工具绑定模式。
- assistant 消息开始展示工具调用过程。
- 确定性工具结果开始具备更高优先级。

## Technical Highlights

- 有工具可用时，模型绑定当前 active tools。
- 无工具可用时，普通问答链路仍然可用。
- 工具调用前显式检查工具存在性、参数归一化和 schema 校验。
- 前端消费结构化 Tool 事件，而不是只渲染字符串。

## Known Limits

- 只接入 `calculator`。
- 不做多工具调度。
- 不做 Agent loop。
- 不做工具权限系统。
- 详细工程验证记录：待补充。

## Next

- 扩展到多个 Tool。
- 建立统一 Tool Registry。
- 继续完善确定性工具结果策略。
