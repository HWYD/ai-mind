# v0.2.3 Release Note

## Summary

v0.2.3 完成 Tasklist Agent Graph Runtime 收口：`/tasklist + @docs://versions/*.md` 不再走 legacy runner 或 runtime switch，而是固定进入 Graph Runtime。

## Completed

- `/tasklist` ready invocation 直接调用 Graph Runtime。
- 删除 legacy runner、legacy runtime wrapper、runtime selector 和 legacy runner test。
- 历史 `AI_MIND_TASKLIST_AGENT_RUNTIME` 被忽略，不再参与运行配置或执行路径判断。
- GraphState 拆掉外层 `agentState` 包裹，改为 Graph-first 分区。
- Graph nodes 返回分区 patch。
- Graph routes 基于显式 state 字段判断。
- 保持 stream chunk、tasklist artifact 和 AgentTracePanel 兼容。
- README 和 env example 已同步 Graph Runtime 单路线。

## Changed

- `AI_MIND_TASKLIST_AGENT_RUNTIME` 不再是运行路线开关。
- `AI_MIND_GRAPH_EVENTS`、`AI_MIND_GRAPH_DEBUG_VIEW`、`AI_MIND_GRAPH_CHECKPOINT` 继续保留。
- Graph Debug Summary 仍只输出脱敏白名单摘要。

## Verification

- `pnpm --dir apps/webapp test`
- `pnpm --dir apps/webapp typecheck`
- `pnpm --dir apps/webapp lint`
- `pnpm --filter @ai-mind/stream-core test`
- `pnpm --filter @ai-mind/stream-core typecheck`
- `git diff --check`

## Known Limits

- 本版不实现 HITL、Durable Agent Run、Resume API 或 Run History。
- Graph checkpoint 仍是显式配置的展示和调试能力，不是生产持久化、Resume 或产品级恢复能力。
- 未来持久化和恢复能力需要单独版本设计。
