# v0.3.6 Release Note

## 摘要

v0.3.6 是 `Controlled Delivery Chain MVP`。
本版在 `@demo://` public demo 资源边界内新增 `/delivery-chain`，支持 demo scenario 和 inline requirement 两类输入，并输出受控的 Plan、Task、Review 报告。

## 已完成

- 新增 `specs/036-controlled-delivery-chain-mvp/` 完整规格资产。
- 新增 ADR-0010，记录 Delivery Chain、artifact-first handoff 和 future multi-agent roadmap。
- 新增 `/delivery-chain` command route，并在内部使用 `DeliveryChainGraph` 承载受控的 LangGraph 顺序工作流。
- 支持 `/delivery-chain + @demo://scenarios/*/requirement.md`。
- 支持 `/delivery-chain <inline requirement>`。
- 复用 v0.3.5 `@demo://` resolver，继续拒绝 `@docs://`、`@specs://`、`file://`、绝对路径和 path traversal。
- 固定执行 PlanStage、TaskStage、ReviewStage，并输出非持久化 Delivery Chain Report。
- `@` resource picker 在 `/delivery-chain` 下只展示 demo scenario requirement。
- 快速访问新增 Delivery Chain demo 示例。
- 更新 README、roadmap、public version/release/tasklist 和 package version 到 `0.3.6`。

## 已知边界

- 本版对外只暴露 `/delivery-chain`，不暴露 `/plan`、`/task`、`/review`。
- TaskStage 不调用现有 Tasklist Agent HITL Graph。
- 不实现 `@artifact://`、artifact persistence、nested HITL 或 chat persistence。
- 不修改 Tasklist Agent Graph topology、HITL contract、checkpoint resume 语义、stream protocol、frontend reducer、Prisma schema、PostgresSaver schema。
