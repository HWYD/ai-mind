# v0.0.9 Release Note

## Summary

`v0.0.9` 将现有 `reader-skill` 接入本地 `stdio` MCP Host MVP。MCP 作为能力来源层进入项目，同时当前 Skill Runtime 和对外能力名保持稳定。

## Completed

- 新增基于官方 TypeScript MCP SDK 的本地 MCP Host 基础层。
- 新增 `weather-server`，提供 MCP Tool 能力。
- 新增 `project-files-server`，提供 MCP Resource 能力。
- 保持模型可见能力名 `city-weather` 和 `local-text-read` 不变。
- 新增 Resource 流式事件与 Resource card。
- 保持 `utility-skill` 和普通聊天主链稳定。

## Changed

- `city-weather` 底层映射到 `weather-server.get_weather`。
- `local-text-read` 底层映射到项目文件 MCP Resource 读取。
- Tool 和 Resource part 可以携带 MCP 来源信息。
- 前端可以将 Resource 作为独立卡片类型展示。

## Technical Highlights

- MCP client manager 按 `serverId` 复用 client。
- MCP adapters 隔离协议响应与 runtime 消费结构。
- Tool 与 Resource 在后端协议和前端展示上都完成分离。
- MCP 相关代码保持在服务端 runtime 路径。

## Known Limits

- 仅支持本地 `stdio` MCP。
- 不支持 remote MCP。
- 不做 Agent Runtime。
- 不做 Resource Picker。
- 不做 MCP server 状态面板。
- 不做多 server 编排。

## Next

- 继续稳定 `reader-skill` 作为 MCP capability 消费层。
- 补充更多 Tool 和 Resource 失败场景测试。
- 以更清晰的 MCP 边界为后续 Agent 或持久化演进做准备。
