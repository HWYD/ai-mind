# v0.1.0 Release Note

## Summary

`v0.1.0` 引入 AI Mind 第一个受控单 Agent：`Version Plan to Tasklist Agent`。

它基于用户显式引用的版本方案生成 tasklist 草稿，并通过确定性的结构质量门完成一次可观察、可约束、可回归的 Agent 闭环。

## Completed

- 新增受控单 Agent：`Version Plan to Tasklist Agent`。
- `/tasklist + @docs://versions/*.md` 成为本版唯一 Agent 入口。
- 新增受控 docs catalog 接口，用于资源菜单枚举 version plan。
- 新增 Agent State Machine，限制 step、补充上下文读取和自动修正次数。
- 新增 `validate_tasklist_structure` deterministic tool。
- 支持 tasklistDraft v1 -> v2 的一次自动修正。
- 新增 Agent Step 流式协议与 `AgentTracePanel`。
- final answer 输出 tasklist 草稿、结构校验结论和人工确认点。

## Changed

- `/tasklist` 从普通 command hint 升级为受控 Agent 入口，但必须显式引用 `docs://versions/*.md`。
- Resource Menu 不再写死所有 version plan 文件，改为通过受控 docs catalog 获取候选。
- Agent 模式下，Resource / Tool 摘要归并进对应 Agent step，避免顶层重复铺开调试卡片。

## Technical Highlights

- Agent 采用 Runtime-controlled path，而不是模型自由规划下一步动作。
- `AgentState` 只保存本轮草稿和校验信息，不持久化、不写 docs 文件。
- `validate_tasklist_structure` 只做结构校验，不做语义质量判断。
- 自动修正最多一次，避免无限循环。
- Agent Step 协议让前端可以展示读资源、生成草稿、结构校验、修正和最终回答等过程。

## Known Limits

- 本版是 Runtime-controlled Agent path，不是让模型自由规划再执行的开放式 Agent。
- 本版不从裸目标直接生成 tasklist。
- 本版不写入 `docs/tasklists/*`。
- 本版不读取历史 tasklist。
- 本版不自动扫描 `docs/versions/*`。
- 本版不做多 Agent、工作流平台或 AgentState 持久化。
- 本版不引入额外语义质量门。
