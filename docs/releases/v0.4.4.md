# v0.4.4 Release Note

v0.4.4 是 `Minimal Multi-thread Chat Sessions`。

本版把 chat memory 从“单 browser session 只有一个会话线程”扩展为“单 browser session 最多保留 10 个最近活跃的 persisted conversations”，同时把“新聊天”收口为纯 draft-first 语义：

- 新增 browser-session scoped Conversation Registry，只记录 persisted recent conversations
- 点击“新聊天”只进入 blank draft，不立即创建 persisted conversation
- 首条 user message 提交时，服务端创建正式 conversation，并把它加入 registry
- 每个 persisted conversation 使用独立的 text-only chat memory thread
- hydration、model-visible context、summary compaction、pinned decisions、final-turn writes 都按 conversation 隔离
- desktop 提供可折叠 sidebar，mobile 提供顶部 trigger + drawer
- streaming / pending review 期间禁用 create / switch，避免写错会话

仍然明确保持不变的边界：

- 不引入 `ChatSession` / `ChatMessage` 业务历史表
- 不把 Tasklist GraphState、HITL payload、Delivery RuntimeArtifact、workflow progress 写入 chat memory
- 不修改 `@ai-mind/stream-core` chunk union
- 不把 conversation UI 做成完整历史管理系统
- 不兼容 legacy `chat:${sessionHash}` 单线程 identity

本轮一致性收口验证结果：

- focused draft-first suites：`16 passed` test files，`136 passed` tests
- `apps/webapp/node_modules/.bin/tsc.cmd --noEmit` 通过
- `node_modules/.bin/eslint.cmd apps/webapp` 通过，仅保留既有 shared UI/layout warnings
- `apps/webapp/node_modules/.bin/next.cmd build` 通过
- `git diff --check` 通过
- desktop / mobile 真实浏览器手动 smoke 仍待执行
