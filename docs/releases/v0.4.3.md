# v0.4.3 Release Note

## 摘要

v0.4.3 是 `Tool & Agent Final Turn Memory`。

本版把 v0.4.2 的 chat memory baseline 从“普通 text chat”扩展到了“安全 final turn”。

刷新后现在可以恢复：

- ordinary tool final answer
- reader / utility / docs summary final answer
- MCP / resource-assisted final answer
- Tasklist final answer text summary
- Delivery final report text

## 已完成

- 普通 tool、authoritative tool、reader / utility、docs summary、MCP / resource final answer 现在都能复用既有 final assistant text capture，并在 completed turn 后进入 chat ThreadState。
- 新增 append-time final-turn adapter / write eligibility guardrail，只允许“用户输入文本 + 最终用户可见文本”进入 memory。
- Tasklist completed / blocked final answer 现在可恢复，但只保存 final answer text summary，不保存 tasklist artifact markdown。
- Delivery completed / blocked final report 现在可恢复，但只保存 final report text；超长时按 8000 字符确定性截断。
- persisted `ChatThreadMessage` 继续只保存 `id` / `role` / `text` / `createdAt`，不新增 `source`、`turnId`、`displayKind`。
- `GET /api/chat/thread` 保持 v0.4.2 DTO 兼容；刷新恢复后的 tool / Tasklist / Delivery final turns 仍按普通 text message 渲染。
- recent messages / context builder / compaction 现在可以处理 persisted structured final turns，但继续只注入 text，不注入 raw transcript。
- Tasklist 和 Delivery final-turn append 命中压缩时，也会 relay `thread-memory-status`，不再等下一轮普通 chat 才看到压缩提示。
- Tasklist HITL resume 在 `agent-resume` 之后的 provider/runtime 失败，错误标准化已和普通 chat 路径对齐。

## 已知边界

- 当前只支持单浏览器单会话 chat memory，不做多会话历史列表。
- 不新增 ChatSession / ChatMessage Prisma 业务表。
- 不做长期记忆、pgvector、LangGraph Store 或 Memory Inspector。
- hydrate 只返回安全 DTO，不暴露 raw checkpoint、raw prompt、provider response、stack、GraphState、RuntimeArtifact、workflow progress 或 subagent raw result。
- Tasklist 仍然只保存 final answer text summary，不让 chat memory 参与 Tasklist checkpoint / resume。
- Delivery 仍然是 run-local workflow，不获得 checkpoint、resume 或 artifact persistence 语义。
- 不新增 final-turn stream chunk，不修改 frontend reducer public shape。
