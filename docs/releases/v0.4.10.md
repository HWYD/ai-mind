# v0.4.10 Release Note

**状态**：Ready for release。实现、数据库迁移、自动化验证和浏览器 smoke 已完成。

## 摘要

v0.4.10 引入 Resumable Agent Streams，让普通聊天、Tasklist Agent 和 Delivery Chain 的 `fetch POST + NDJSON` 流具备断线恢复、幂等提交、显式取消和 terminal/recovery 状态收口能力。

## 主要变化

- 固定使用 resumable envelope：`application/x-ndjson; profile="ai-mind-resumable-v1"`。
- 新增 `StreamRequest`、`StreamRun`、`StreamEvent` 持久化模型和 Prisma migration。
- `POST /api/chat` 对所有初始请求要求 `Idempotency-Key`，duplicate request 返回 JSON replay descriptor。
- 初始 POST 在尚未得到 `runId` 的响应丢失窗口内，会在当前页面使用原 key 和 payload 进行有界重试（最多 3 次 / 20 秒）；replay descriptor 继续走 GET recovery，取消、页面卸载和永久错误不会重试。
- 新增 `GET /api/chat/runs/{runId}/stream`，支持 `Last-Event-ID` / `after` cursor、retained replay、live polling、heartbeat 和 terminal close。
- 新增 `POST /api/chat/runs/{runId}/cancel`，记录 explicit cancel intent 并投影 terminal cancellation。
- Tasklist Agent 的 HITL resume/reject 使用同一个 `runId` 投影 public stream events，不创建第二套 StreamRun。
- 前端 reader/hook 增加 cursor tracking、dedup、gap recovery、retry policy 和状态提示。

- Webapp stable：128 个测试文件 / 860 个测试通过。
- Webapp integration：9 个测试文件 / 27 个测试通过，使用本地 PostgreSQL。
- Stream core：6 个测试文件 / 29 个测试通过，typecheck 通过。
- Database Prisma integration：1 个测试文件 / 2 个测试通过；schema validate 通过。
- Webapp typecheck、相关 lint、production build 和 `git diff --check` 通过。
- 浏览器 smoke：实际流式响应完成，刷新后最终结果可恢复，控制台无应用级错误。

## Follow-up reliability closure

- initial POST recovery 的 20 秒预算已覆盖 in-flight request timeout；预算耗尽时不再无限挂起或追加 POST。
- non-terminal EOF 与 replay descriptor 的首次 GET 失败会继续走 cursor-based GET recovery。
- draft conversation 注册失败会为已创建 StreamRun 投影安全 `failed` lifecycle，避免 orphan `running` run。

当前本地已通过的 targeted validation 包括：

- webapp typecheck；
- route / cancel / recovery / terminal-state targeted Vitest；
- stream-recovery idempotency、three-stream 和 all-streams control-state integration tests；
- ordinary chat、Tasklist Agent 和 Delivery Chain recovery integration coverage。

Fixed-envelope release validation、targeted stream-core/webapp tests、typecheck、lint、controlled recovery smoke 和 production build 均已完成。

## 部署影响

本版本包含 database schema migration。部署前需要确认：

- PostgreSQL 可用；
- Prisma migration 已应用；
- webapp 服务端可以访问 stream recovery tables；
- 作为预发布协议收口，legacy raw NDJSON client 必须随完整 webapp 镜像更新；不提供未协商的旧行为 fallback。

## Non-goals

- 不支持 process-crash active executor takeover。
- 不承诺外部 side effect exactly-once。
- 不迁移到原生 `EventSource`。
- 不保留无限历史事件。
