# v0.4.11 Release Note

**状态**：Ready for release。实现、确定性测试、typecheck 和 lint 已完成。

## 摘要

v0.4.11 引入 Structured Supervisor Review Loop，将 `/delivery-chain` 从固定路由式 Manager 演进为具备有限真实决策能力的 ControlledDeliverySupervisor，同时保持受控边界和兼容性。

## 主要变化

- 新增 `agent-contracts.ts`：角色专属 closed Zod Contract schemas，覆盖 Supervisor pre/post、Plan、Tasks、General/Risk/Boundary Reviewer、ReviewFinding 和 RevisionRequest。
- 新增 `contract-invocation.ts`：最多一次 repair 的安全结构化调用边界，只暴露 `{ path, code }` 摘要。
- 新增 `structured-delivery-manager.ts`：业务生成使用用户选定模型，结构化 Contract 固定使用 `deepseek/deepseek-v4-pro`。
- 新增 `delivery-chain-model-set.ts`：分别创建用户业务模型和固定 Contract 模型的 handle，后者在服务端验证 `jsonOutput` 能力。
- `controlled-delivery-manager.ts` 重写：Supervisor 输出结构化意图而非 invocation-only tool calls，Runtime 校验后通过内部 worker tools 执行。
- `delegation-policy.ts` 演进：从单一 `maxToolCalls=5` 变为按阶段预算，包含每阶段 repair 上限、Review cycle 上限和 Revision 上限。
- `runtime-artifacts.ts` 新增：Runtime 分配稳定的 artifact ID、revision、cycleId 和 findingId。
- `report-synthesis.ts` 重写：只消费 typed artifacts/ReviewBundle，删除 Markdown 正则、metadata cast 和基于文本的 conflict 判断。
- `workflow-progress.ts` 新增：Supervisor decision、post-review decision 和 revision 内部进度步骤；返修后不进入 Re-review。
- 新增 8 case 冻结 evaluation manifest、三 baseline test-side adapters 和确定性 harness。

## Demo 案例

- 新增 `register-login`（注册登录系统）、`guangzhou-3-day-trip`（广州三天旅行计划）、`frontend-learning-plan`（前端学习计划）三个公开案例。
- `@` 菜单标签改为中文，图标 hover 显示文档路径 tooltip。
- 移除旧的 `langsmith-safe-mode` 和 `delivery-chain-resource-boundary` 案例。

## 兼容性

- `/delivery-chain` 的现有 public command 和输入方式保持兼容。
- 普通 chat 和 `/tasklist` 不受影响。
- 不修改 stream protocol public shape、frontend reducer 或 Tasklist Agent Graph。

## 验证情况

- 58 个实现任务完成（T001–T058）。
- 确定性测试：133 文件 / 914 测试通过。
- typecheck 和 lint 通过。
- 外部模型评测 harness 和 fixture 已就绪，真实 provider 评测待后续执行。
