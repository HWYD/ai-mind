# v0.0.8 Release Note

## Summary

`v0.0.8` 新增 `reader-skill`，接入天气查询和本地文件读取，并同步统一前端组件基线。

## Completed

- 新增 `reader-skill`。
- 新增 `city-weather`。
- 新增 `local-text-read`。
- 自动模式支持高置信天气和文件读取路由。
- 前端 Skill 模式统一为自动、实用、读取。
- 正式接入 `shadcn/ui` 与 `radix-vega` 组件基线。

## Changed

- 版本主线从写作类 Skill 收敛为外部上下文获取 Skill。
- Skill Runtime 开始区分 `utility-skill` 与 `reader-skill`。
- 前端输入区、错误条、推理面板、Tool 卡片和空状态进入统一组件语言。

## Technical Highlights

- `reader-skill` 只暴露天气和本地文件读取相关工具。
- `local-text-read` 保持严格文件访问边界。
- 自动路由采用高置信规则，避免乱命中。
- Tool 状态在 UI 中区分执行中、完成和失败。

## Known Limits

- 天气服务依赖外部可用性，可能存在波动。
- 本地文件读取仅限项目根目录直接文本文件。
- 不做 MCP。
- 不做 Agent。
- 不做网页抓取或文件浏览器。

## Next

- 稳定 `reader-skill`。
- 补充测试与文档。
- 后续再评估网页读取或 MCP 能力接入。
