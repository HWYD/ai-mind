# v0.0.7 Release Note

## Summary

`v0.0.7` 在 Multi-Tool Runtime 之上新增第一层 Skill Runtime，并通过 `utility-skill` 验证高层能力封装是否成立。

## Completed

- 新增 Skill Definition 和 Skill Registry。
- 落地第一版 `utility-skill`。
- 支持 `options.skill`。
- Runtime 可按 Skill 的 `allowedTools` 过滤工具。
- 新增 `unit-convert`。
- 保持 `reasoning / tool / text` 协议不变。

## Changed

- `/` 默认进入 `utility-skill` 实用模式。
- Runtime 开始支持 Skill prompt 注入。
- Tool 不再只是裸能力集合，而可以被 Skill 组织成任务模式。

## Technical Highlights

- Skill 不直接执行 Tool，只定义高层约束和能力边界。
- `utility-skill` 统一日常实用任务输出风格。
- `unit-convert` 支持长度、重量和温度换算。
- 普通开放式问答仍能自然回答。

## Known Limits

- 不做自动 Skill 选择。
- 不做 Skill UI。
- 不做多 Skill 串联。
- 不做 MCP。
- 不做 Agent。

## Next

- 增加第二个 Skill，验证多 Skill 能力分工。
- 增加更高识别度的外部上下文工具。
- 逐步为 MCP 与 Agent Runtime 做铺垫。
