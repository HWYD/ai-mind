# v0.0.4 Release Note

## Summary

`v0.0.4` 完成本地聊天链路的结构化收口，建立 `LangChain.js + Ollama + Zod + NDJSON + Streamdown` 的最小可扩展架构。

## Completed

- 使用 `LangChain.js` 接入本地 Ollama 模型。
- 建立自定义 `/api/chat` 与 NDJSON 流式响应。
- 使用 `Zod` 校验请求与流式 chunk。
- 引入 `typed parts` 消息模型。
- 使用 `Streamdown` 渲染 Markdown。
- 前端通过自定义 `useChatStream` 管理流式消息。

## Changed

- 聊天输出从单字符串逐步转向结构化 parts。
- 前端从简单文本追加转向按 chunk 合并消息状态。
- 服务端开始承担模型调用、流式转换和协议兜底职责。

## Technical Highlights

- 自定义 NDJSON 协议便于后续扩展 reasoning、tool、source 等 part。
- `Zod` 作为请求和协议边界。
- `Streamdown` 适配流式 Markdown 渲染。
- 多轮上下文先保持前端最小实现。

## Known Limits

- 不支持 Tool Calling。
- 不支持长期记忆。
- 不支持 source 引用。
- 不支持多会话管理。
- 详细工程验证记录：待补充。

## Next

- 在当前聊天骨架上继续接入 Tool Calling。
- 扩展结构化 part 类型。
- 继续增强错误处理和前端流式状态管理。
