# v0.2.4 Release Note

## Summary

v0.2.4 完成 Tasklist Agent Graph 单状态模型收口：`/tasklist + @docs://versions/*.md` 仍固定进入 Graph Runtime，同时生产 graph nodes 不再通过旧 AgentState 整包 adapter 往返转换。

## Completed

- GraphState 作为 Tasklist Agent 生产路径的内部运行态事实源。
- 初始 GraphState 直接由 `runId`、`versionPlanReference` 和 runtime config 创建。
- 删除生产代码中的 `toVersionPlanTasklistAgentState()` / `createGraphStateUpdateFromAgentState()` 过渡 adapter。
- Graph nodes 直接消费 GraphState 分区并返回 GraphState patch。
- 领域状态机只保留 GraphState guard / apply 路径。
- GraphState reducer 合并分区 patch，减少 node 手动回填完整分区的风险。
- Graph routes 的成功路径基于显式业务字段判断。
- Graph tests 直接断言 GraphState、node patch 和显式 route 字段。
- Stream chunk、tasklist artifact、AgentTracePanel 和 Debug Summary 兼容。

## Changed

- 旧 `VersionPlanTasklistAgentState` 类型和旧状态机 API 已移除。
- Prompt 构造只接收最小 prompt state，不再要求完整 AgentState。

## Known Limits

- 本版不实现 HITL、interrupt、Resume API、Run History 或数据库持久化。
- Graph checkpoint 仍是显式配置的展示和调试能力，不是生产持久化、Resume 或产品级恢复能力。
