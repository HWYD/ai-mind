# v0.3.7 Release Note

## 摘要

v0.3.7 是 `Delivery Chain Workflow Progress Presentation`。  
本版为 `/delivery-chain` 新增通用 `workflow-progress-*` 过程展示事件和前端 process panel，让固定阶段 workflow 在执行中可见、完成后可折叠回顾，同时增强 Delivery Chain Report 的分段展示。

## 已完成

- 新增 `specs/037-delivery-chain-workflow-progress-presentation/` 完整规格资产。
- 更新 `docs/architecture/agent-runtime-roadmap.md`，明确 v0.3.7 的 workflow progress 范围和后续 guardrails。
- 在 `@ai-mind/stream-core` 新增 `workflow-progress-start`、`workflow-progress-step`、`workflow-progress-end`。
- 在 webapp `chatStreamChunkSchema`、message model 和 reducer 中接入 `workflow-progress` message part。
- `/delivery-chain` runtime 围绕 `load -> plan -> task -> review -> report` 固定阶段发出 progress events。
- 新增 compact `WorkflowProgressPanel`，执行中默认展开，完成后默认折叠。
- 新增 Delivery Chain Report section presentation，并保留 Markdown fallback。
- 保持 v0.3.6 compact resource grouping，不影响 `/tasklist`、AgentTracePanel 和普通资源/工具展示。
- 更新 README、public version/release/tasklist 和 package version 到 `0.3.7`。

## 已知边界

- 本版只让 `/delivery-chain` 消费 `workflow-progress-*`。
- 不复用 Tasklist Agent 的 `agent-graph-*` 时间线 UI。
- 不实现 `@artifact://`、artifact handoff、artifact persistence 或 chat persistence。
- 不实现 checkpoint、interrupt、HITL、resume。
- 不修改 Tasklist Agent Graph topology、HITL contract、Prisma schema 或 PostgresSaver schema。
- step details 是 curated safe summary，不是通用 tool/resource/prompt 日志回放。
