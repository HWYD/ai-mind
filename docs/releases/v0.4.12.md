# v0.4.12 Release Note

**状态**：Ready for release。实现、确定性测试、typecheck 和 lint 已完成。

## 摘要

v0.4.12 发布受控 Image Generation Agent：通过 `/image` 显式进入单张文生图，并在当前会话展示安全进度、临时预览和下载。

## 主要变化

- ImageBrief、结构化 Prompt 规划、检查和最多一次自动修正由独立 LangGraph `StateGraph` 执行。
- 固定 `doubao-seedream-5.0-lite` Provider 在服务端调用，复用已有 Doubao Key。
- ImageGenerationRun 支持 active lease、幂等、取消、临时结果过期和所有权控制。
- UI 支持公开 ImageBrief、工作流耗时、同源 Blob 预览、下载与过期/失败提示。
- `ChatStreamChunk` 增加安全的 image parts，`StreamRun` 增加 `image_generation` 类型。
- `/api/chat/runs/{runId}/image` 为临时结果提供校验后的同源读取入口；Provider URL 不进入浏览器。
- `planningModelCalls <= 5`、`promptRevisionCount <= 1`、`generationCount <= 1` 均由运行时守卫。
- Provider 前的原子生成标记避免并发或晚到结果造成第二次生成。
- 进度流记录安全阶段耗时和服务端总耗时；120 秒后仍保持处理中，直到存在明确终态。

## 配额限制

- `/image` 使用独立每日配额：默认每浏览器 Session 3 次、每 IP 10 次（可配置 10–20）。
- 无效、重放或 active-conflict 请求不消耗配额；本版配额为进程本地内存实现。

## 已知限制

- 仅支持单张文生图；不支持编辑、重绘、扩图、去背景、参考图和多图。
- 不提供 HITL、持久化图片库、对象存储、成本估算或进程崩溃后的 Provider 续跑。
- 临时 Blob 预览不跨刷新恢复。

## 兼容性

- 普通 chat、`/tasklist` 和 `/delivery-chain` 不受影响。
- 不修改 stream protocol public shape 中与图片无关的部分。

## 下一步

后续版本将基于真实使用反馈，再评估专业图像编辑能力与长期媒体存储；不会把它们隐式并入当前 Agent。
