# v0.3.2 Release Note

## 摘要

v0.3.2 是 Spec Kit CLI + Codex Skills Dual-track Pilot：它不新增业务功能，而是在 v0.3.1 治理基线上，真实验证官方 Spec Kit CLI、Codex skills 和人工等价流程如何在 AI Mind 中协同工作。

## 已完成

- 新增 `specs/032-spec-kit-cli-codex-skills-pilot/`。
- 新增 ADR-0006，接受“CLI + Codex skills 双轨 pilot + 人工 fallback”策略。
- 新增 `docs/architecture/spec-kit-tooling.md`。
- 新增项目内 `speckit-clarify`、`speckit-checklist`、`speckit-analyze` 三枚 lightweight pilot skills。
- 真实试跑官方 Spec Kit CLI，并确认 `codex --skills` 方向与 AI Mind 当前结构兼容。
- 在临时目录验证官方 CLI 会生成完整 `.specify/`、PowerShell scripts 和 `.agents/skills/speckit-*` 套件。
- 用户已在全新 Codex 会话中人工校验项目内 `speckit-*` skills 可发现、可触发。
- lockstep package version 更新到 `0.3.2`。

## 已知边界

- 本版仍是 pilot，不是强制化落地。
- 官方 CLI 不作为团队默认必装工具。
- 官方生成物没有直接合并进当前仓库。
- 当前仓库内三枚 `speckit-*` skills 仍是 AI Mind 的 lightweight pilot，不等于官方 full skills 套件。
- 最新业务运行时 baseline 仍是 v0.3.0 Tasklist Agent HITL Checkpoint Resume MVP。
