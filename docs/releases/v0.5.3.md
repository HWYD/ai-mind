# v0.5.3 发布记录

**状态**：本地版本收口完成；尚未创建 tag 或 GitHub Release。

## Summary

v0.5.3 为长聊天历史引入统一的动态高度虚拟列表。用户可以继续浏览文本、图片和执行过程卡片，同时避免完整消息历史同时占用页面 DOM。

## Completed

- 非空消息列表使用免费 `react-virtuoso@4.18.12` 管理可见区渲染、底层滚动和动态尺寸测量。
- 聊天业务 Scroll Policy 保留历史首次定位、流式末尾跟随、用户阅读锁定和“回到底部”语义，不再与 virtualizer 并行控制像素位置。
- 图片、Markdown、代码与各类执行过程卡片使用结构化初始高度估算；稳定历史可使用与展示条件严格匹配的本地高度提示改善后续挂载。
- 重要展开状态在离屏回收后保持；静态阅读不会因为图片、详情、Composer 或列表重测而被自动拉回末尾。
- 历史会话的骨架、消息列、Composer 和原生 scrollbar gutter 采用统一布局边界，避免刷新和会话切换时的横向偏移、入口闪现或 scrollbar 突变。

## Changed

- 浏览器本地持久化新增 `message-height-hints` 性能提示 store，仅保存受限的几何元数据；它不保存消息正文、图片 Blob、阅读位置或完整列表状态。
- 本地开发环境提供独立的消息虚拟化准备入口和 fixture 工具，用于浏览器回归；它不进入产品菜单、不调用聊天 API，也不改变正常会话写入策略。

## Technical Highlights

- 单一物理滚动所有权：Virtuoso 负责滚动与测量，AI Mind 只表达业务滚动意图。
- `followOutput={false}`，避免 library auto-follow 与业务策略冲突。
- 稳定 message identity、结构化高度估算和真实 DOM measurement 协同处理异构内容。
- 高度提示按会话、消息、列宽、渲染签名和默认展示状态隔离；缺失或失效时自动降级，不影响会话显示。

## Verification

- 定向自动化、typecheck、lint、稳定测试与 diff integrity 检查已完成。
- 已在 1,000 条混合 fixture 与本地最长真实会话完成桌面和移动端的浏览、刷新、拖拽、图片、详情与流式行为回归。
- 性能数值保留为后续诊断信息；不用于改变本版本已验证的滚动正确性边界。

## Known Limits

- 离屏消息不参与浏览器原生全文查找，也不会同时存在于可访问树。
- 高度提示是浏览器本地、可失效的性能优化，不保证首次渲染命中，也不跨设备同步。
- 本版本未引入服务端分页、向上加载或阅读位置恢复。

## Next

后续可在相同消息视口边界上评估服务端窗口化、搜索体验或更大规模历史的性能优化；这些方向不属于 v0.5.3。
