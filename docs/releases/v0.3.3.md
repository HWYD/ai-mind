# v0.3.3 Release Note

## 摘要

v0.3.3 是 Spec Kit Full Skills Default Entry：它不新增业务功能，而是在 v0.3.2 dual-track pilot 之后，引入 official Spec Kit full skills 作为 AI Mind Level C / D 复杂变更的默认入口。

## 已完成

- 新增 `specs/033-spec-kit-full-skills-default-entry/`。
- 新增 ADR-0007，接受 official full skills default entry 策略。
- 引入 official `speckit-*` full skills。
- official baseline 固定到 `github/spec-kit@v0.11.9` / `specify-cli 0.11.9`。
- 同步 official `.specify/scripts`、`.specify/templates`、`.specify/integrations` 和 agent-context extension。
- 保留 AI Mind 自有 constitution，不覆盖 `.specify/memory/constitution.md`。
- 移除旧 lightweight pilot skills 对 `speckit-*` 命名空间的占用。
- 更新 Spec Kit tooling、AI coding workflow、spec-driven development、AGENTS、README 和 specs 索引。
- 新增 template overrides 说明，先建立边界，不立即覆盖 official core templates。
- 将 `.specify/feature.json` 视为本地当前 feature 指针并加入 ignore，不作为长期事实源提交。
- lockstep package version 更新到 `0.3.3`。

## 已知边界

- 本版不修改 runtime、Graph、Prisma schema、PostgresSaver、stream protocol、API route 或前端 reducer。
- 本版不接入 CI 强制门。
- `speckit-taskstoissues` 是 optional，不进入默认主流程。
- Level A / B 不强制 full skills。
- 新 Codex 会话中的 skills 可发现性仍建议人工补验。
- 最新业务运行时 baseline 仍是 v0.3.0 Tasklist Agent HITL Checkpoint Resume MVP。
