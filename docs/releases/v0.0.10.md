# v0.0.10 Release Note

## Summary

`v0.0.10` 是结构升级版本。它将聊天主链收口成更清晰的 runtime 边界，并将稳定流式内核抽成内部 workspace 包 `@ai-mind/stream-core`。

## Completed

- 将 `chat-service` 收口为薄 facade。
- 新增正式聊天 runtime 编排层。
- 统一流式错误与终态生命周期语义。
- 将 authoritative answer 升级为 runtime 策略。
- 新增内部 workspace 包 `@ai-mind/stream-core`。
- 统一 webapp 与 package 的测试边界。

## Changed

- 聊天主链收口为 `route -> chat-service facade -> runtime -> skills / tools / mcp`。
- 流式协议类型、生命周期、错误 helpers、static writers 和 NDJSON writer 下沉到 `stream-core`。
- Webapp 通过 workspace package 消费 `stream-core`。
- 测试按 app 与 package 边界重新组织。

## Technical Highlights

- `StreamLifecycle` 保证单一终态流行为。
- `error` chunk 使用统一协议结构。
- `stream-core` 暴露 root、protocol、web 三个入口。
- package 输出 CommonJS、ESM 和类型声明。

## Known Limits

- 没有把整个 chat runtime 抽成 package。
- 业务编排继续保留在 webapp runtime。
- 不做 Agent Runtime。
- 不接持久化层。
- 本版本不扩展新的 MCP 能力范围。

## Next

- 继续保持 runtime 边界稳定。
- 将 `stream-core` 作为后续 app 或 service 复用的流式内核。
- 在业务编排边界足够稳定前，不急于继续抽包。
