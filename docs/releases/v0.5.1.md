# v0.5.1 发布记录

**状态**：发布候选；所有 workspace package version 已锁步更新为 `0.5.1`，本地 CI 等价验证已通过，远端 macOS arm64 job 待提交后执行。

## Summary

v0.5.1 提升会话导航、图片生成反馈与图片结果可靠性，并为桌面和移动端补充固定项目入口。

## Completed

- 最近会话容量扩至 50 条，桌面长标题支持按需单次滚动展示。
- 已验证图片 Blob 可在当前浏览器或 Electron profile 刷新后恢复，使用 30 张或 100 MiB 的 LRU 上限。
- 图像生成与结果读取统一使用流光占位；普通提示词的误拦截增加字面冲突复核。
- 图像规划节点和图片 Provider 仅在确定可恢复的错误下有限重试。
- 侧栏和移动抽屉新增访客项目菜单；浏览器打开 GitHub，Electron 复制链接。

## Known Limits

- 图片缓存不跨设备或 profile，同源临时内容和本地缓存都不可用时需重新执行 `/image`。
- Provider 的 `5xx` 重试可能带来重复结果或额外计费；未知投递状态不会重试。
- 不包含全量历史、会话搜索、服务端图片库、图片编辑或新的 Electron IPC。

## Verification

根目录与全部 workspace 已锁步使用 `0.5.1`；本地 stable、状态型 integration、Windows 桌面打包/制品校验和 Linux Docker 构建均通过。最终远端状态以提交后的 GitHub Actions 为准。
