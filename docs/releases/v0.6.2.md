# v0.6.2 发布收口记录：AMap MCP Tools

**状态**：2026-09-27 完成本地实施与验收收口；尚未创建 Git tag、GitHub Release 或远程发布。

## 交付内容

- 九项固定高德 MCP 只读 Tool 通过 `GeneralToolPolicy -> Tool Registry -> Tool Runtime -> MCP Client` 接入 General ReAct。
- Key 只在 server env 使用，缺失时 fail closed；模型、Trace、`StreamEvent` 与错误输出不保留凭据或原始地图 payload。
- 用户或模型生成的位置、城市和 POI ID 均作为候选，经 schema、GCJ-02/范围和出站安全校验后才到 Provider；固定远端映射通过真实 MCP 契约验证。
- 远程只读的 timeout、取消、retry permit、deadline 与安全错误分类复用通用 Tool Runtime；明确瞬态失败最多重发同参两次，已通过 schema 但无法归类的只读 MCP `isError` 最多重发一次，参数、权限、已识别额度、空和 malformed 结果由模型在后续 Action 修正。
- 同一 `amap-maps` Key 的短时调用按每批最多 3 条、整批结束后冷却 800ms 排队；取消或关闭前仍在队列的请求不外发。500ms 的真实 smoke 已通过，800ms 是更保守的用户配置。该保护只在单个 webapp 进程内生效。
- AMap 跨层错误只保留稳定 code 与安全状态；明确空 POI 为成功的“未找到地点”，逆地理只投影国家、省、市、区。
- Trace 以具体地图用途展示，失败只显示固定安全类别，不展示 provider 或内部工具名。
- `deepseek-v4-pro` 在用户开启“深度思考”时显式启用 reasoning；工具保持模型的自动选择语义。
- Tool result 统一作为即时、精确或外部事实依据；结果缺失或失败时如实说明，不以模型常识、估算、同类候选或调用顺序补齐。
- 已完成受限收口的 Run 显示“已完成思考”；只有真实失败显示“处理未完成”。受限 finalizer 继承 Tool result 事实边界，路线空结果不根据坐标或经验补写时长。
