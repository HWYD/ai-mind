# v0.0.6 Release Note

## Summary

`v0.0.6` 将项目从单 Tool Calling 闭环推进到多 Tool Runtime 雏形。

## Completed

- 引入统一 Tool Registry。
- 接入 `calculator`、`datetime`、`text-transform`。
- 增强 Tool part 展示。
- 增加参数校验、参数归一化和工具执行兜底。
- 保持普通聊天主链稳定。

## Changed

- Runtime 开始面向统一工具接口，而不是具体工具文件。
- 多个工具通过 registry 组织和查询。
- 工具错误可以被结构化展示。
- 确定性工具结果开始有更清晰的优先策略。

## Technical Highlights

- 每个 Tool 自带 schema、归一化、展示配置和执行逻辑。
- Runtime 兜底覆盖参数非法、工具未注册、工具执行失败和流式取消。
- Tool 展示支持标题、动作、输入输出和错误状态。

## Known Limits

- 不做 Skill 系统。
- 不做 MCP。
- 不做 Agent。
- 不做并行工具执行。
- 不做长期记忆。

## Next

- 在 Tool Runtime 之上引入第一层 Skill Runtime。
- 继续补充确定性工具能力。
- 让高层能力模式逐步成形。
