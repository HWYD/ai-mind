# v0.4.0 Release Note

## 摘要

v0.4.0 是 `Controlled Agent-as-tool Delivery Manager MVP`。

本版用 `ControlledDeliveryManager` 接管 `/delivery-chain`，让 Manager 通过受控 tool-calling 串行委派 `plan-subagent`、`task-subagent`、`review-subagent`，并在内部完成 RuntimeArtifact handoff 与最终报告汇总。

## 已完成

- 新增 `apps/webapp/lib/ai/runtime/delivery-chain/manager/`，承载 delivery-chain-local manager contracts、policy、subagent tools、workflow progress mapping 与 report synthesis。
- 新增 `ControlledDeliveryManager`，固定顺序执行 `plan -> task -> review`，并强制 `maxToolCalls = 3`、no parallel、no nested delegation、fail closed。
- `/delivery-chain` 主路径切换到 Manager，不再保留旧的 graph main path。
- 子 Agent tool result 改为强 JSON Schema contract，并在 runtime 内部转换成 run-local `RuntimeArtifact`。
- 继续复用 `workflow-progress-*`，但 step 语义改为 Manager delegation。
- 保持 Delivery Chain Report headings 兼容，不改 public report surface。
- 保持 `@demo://` boundary，不读取真实仓库资源。
- 保持 `/tasklist`、Tasklist Graph topology、HITL contract、checkpoint / resume contract 不变。
- 更新 `specs/040-controlled-agent-as-tool-delivery-manager-mvp/`、README、public version/release/tasklist 和 package version 到 `0.4.0`。

## 已知边界

- 仍然只有 `/delivery-chain` 一个 Delivery Chain public command。
- 不新增 `/plan`、`/task`、`/review`。
- 不新增 `@artifact://`、artifact persistence、chat persistence、DB schema 或 Prisma migration。
- 不实现 free supervisor、dynamic routing、parallel subagents、nested subagents、HITL-aware delegation。
- 当前模型不支持 tool-calling 时直接安全失败，不降级成 runner fallback。
- RuntimeArtifact 只在 run-local runtime 内部流转，不进入 `artifact-*` stream chunks 或 frontend `message.artifacts`。
