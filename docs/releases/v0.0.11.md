# v0.0.11 Release Note

## Summary

`v0.0.11` 新增 Capability Model、Skill Metadata、Local Prompt 和单个 Remote MCP 验证闭环。Tool、Resource、Prompt 现在可以被统一描述，并在固定 Skill 场景中被 runtime 消费。

## Completed

- 新增覆盖 `tool`、`resource`、`prompt` 的统一 Capability Model。
- 新增结构化 Skill metadata 与 capability selectors。
- 新增 local Prompt capability：`local-file-summary`。
- 新增 remote MCP app：`apps/project-assistant-service`。
- 新增 mock remote Resource、Prompt、Tool capability。
- 为 `reader-skill` 新增最小 runtime capability 消费链路。
- 前端流式协议支持 Skill 与 Prompt 执行事实。

## Changed

- Skill definitions 现在暴露结构化 surface 信息。
- MCP server definitions 可以描述 local 与 remote capability 来源。
- Runtime 可以消费固定 remote capability 场景，并把结果注入最终回答上下文。
- 前端可以展示 capability 类型、source、location、server、status 和 errors。

## Technical Highlights

- Capability Model 统一描述层，不统一执行链。
- Prompt 成为 Tool / Resource 之外的一等 capability。
- Remote MCP 使用 Streamable HTTP 和 mock 鉴权。
- Capability 失败进入统一流式错误协议，不会直接中断整轮回答。
