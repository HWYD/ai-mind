# v0.3.1 Release Note

## 摘要

v0.3.1 是 Spec Kit Governance Baseline：它不新增业务功能，而是把 AI Mind 后续版本开发所需的 constitution、spec、ADR、AI coding workflow 和 PR checklist 固化到仓库中。

## 已完成

- 新增 `.specify/memory/constitution.md`。
- 新增 v0.3.0 released baseline specs。
- 新增 v0.3.1 governance specs。
- 新增 ADR 目录、模板和首批 5 个 ADR。
- 新增 AI coding workflow、spec-driven development 和 Tasklist Agent runtime boundary 文档。
- 新增 Level C / D 专用的 clarify、checklist、analyze 质量闸门规则，小改不强制执行。
- 同步 `docs/architecture/agent-runtime.md` 中 v0.2.4 / v0.3.0 后的 GraphState 与 durable resume 事实。
- 新增 PR template。
- README 增加治理入口。
- lockstep package version 更新到 `0.3.1`。

## 已知边界

- 本版不安装 Spec Kit CLI。
- clarify、checklist、analyze 可以通过 Codex skills、slash command 或人工等价检查执行。
- 本版不修改运行时代码。
- v0.3.0 浏览器级 HITL smoke 的人工复验状态不在本版解决。
