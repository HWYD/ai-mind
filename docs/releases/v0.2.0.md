# v0.2.0 Release Note

## Summary

`v0.2.0` 将 `Version Plan to Tasklist Agent` 的编排层迁移到 LangGraph `StateGraph`。

Agent 仍然只通过 `/tasklist + @docs://versions/*.md` 启动，不开放自由规划、自由 tool calling 或自动写文件。

## Completed

- 新增 LangGraph `StateGraph` runner。
- 新增 legacy / graph runtime selector。
- 新增集中 runtime config。
- 抽取共享 step operation，legacy runner 和 graph runner 共用业务步骤。
- 将 `PlanningDecisionAction` 映射为 graph conditional edge。
- 将 `WarningDisposition` 映射为 graph conditional edge。
- 新增 graph node / route / state patch stream chunks。
- `AgentTracePanel` 支持 graph timeline。
- 新增 development-only memory checkpoint。
- 新增脱敏 Debug Summary，并在 Trace 面板折叠展示。
- 保持 Agent Text Artifact 最终 tasklist 展示语义不变。

## Runtime Default

release 默认仍保持 `legacy`：

```text
AI_MIND_TASKLIST_AGENT_RUNTIME=legacy
AI_MIND_GRAPH_EVENTS=off
AI_MIND_GRAPH_CHECKPOINT=off
AI_MIND_GRAPH_DEBUG_VIEW=off
```

开发验证 graph 时可显式开启：

```text
AI_MIND_TASKLIST_AGENT_RUNTIME=graph
AI_MIND_GRAPH_EVENTS=on
AI_MIND_GRAPH_CHECKPOINT=memory
AI_MIND_GRAPH_DEBUG_VIEW=on
```

## Known Limits

- 本版仍然不是通用 Agent Runtime。
- 本版不做多 Agent。
- 本版不开放自由 tool calling。
- 本版不从裸目标生成 tasklist。
- 本版不写入 docs 文件。
- 本版不读取历史 tasklist。
- 本版不提供前端 runtime switch。
- 本版不做运行中 fallback。
- 本版不做 production checkpoint。
- 本版不做 pause / resume / replay / interrupt / state edit / history list。
- 本版不直接透传 LangGraph 原始 debug stream。
