# v0.5.0 发布记录

**状态**：代码已合并到 `main`，最新版本已部署线上；公开 Beta 仍需维护者完成生产 verifier 与双平台 fresh-install smoke 后手动触发。

## 范围

公开 GitHub Pre-release 提供 Windows x64 与 macOS arm64 的 `Unsigned Experimental Preview` 安装包。每个平台包含安装包、`desktop-release.json`、SHA-256 和安装说明。

## 不包含

- Authenticode、Developer ID、notarization、自动更新、遥测和 SBOM/provenance
- macOS Intel/universal、Windows ARM64、Linux、离线 AI Runtime
- 可编辑服务地址、TLS 绕过、诊断自动上传或通用 IPC/文件 API

## 发布顺序

1. 维护者部署同一 source commit 并运行生产 verifier。
2. 维护者手动触发 `.github/workflows/desktop-public-preview.yml`，确认 `production_verified=true`。
3. 检查 GitHub Pre-release 的双平台资产、manifest/hash 和安装说明。
4. 维护者完成 Windows/macOS arm64 fresh-install smoke 并回填验收台账。
