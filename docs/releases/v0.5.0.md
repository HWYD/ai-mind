# v0.5.0 发布记录

**状态**：公开 `v0.5.0-public-beta` 已发布；release closing 仍未验收

## 范围

为既有 AI Mind Web 应用提供 Windows x64 与 macOS arm64 的 Electron 在线宿主。应用使用固定的受信 HTTPS Origin、严格的 compatibility 准入、本地恢复页、隔离的浏览器 profile 和收紧的原生权限；打包边界为 GitHub Pre-release 中未签名的公开 Beta。

## 不包含的能力

- 正式签名发行、Developer ID 签名、公证或自动更新
- macOS Intel x64 或 universal binary
- 本地/离线 AI Runtime、数据库、模型、MCP、Tool、Skill 或 Agent 的迁移
- 可编辑服务地址、HTTP/TLS 绕过、诊断上传或通用 IPC/文件 API

## 交付与回退

`v0.5.0-public-beta` 已在 GitHub 作为公开 Pre-release 发布，目标 commit 为 `a39dc9f4f7424dbf787a3df6219a93a069b82326`：<https://github.com/HWYD/ai-mind/releases/tag/v0.5.0-public-beta>。它提供 Windows x64 安装器、macOS arm64 DMG、平台 manifest、SHA-256、安装说明和 README，共 9 个未签名预览 assets。

compatibility API 与 Web security headers 仍只能通过既有服务端部署链路上线；发布策略要求同一 commit 的 production verification、安装器/manifest/SHA-256 核验和发布后的双平台安装 smoke 均有可追溯证据。

同一产品的手动覆盖安装会保留桌面 profile。macOS 首次启动仅按文档使用 Finder 的“右键打开”流程；ad-hoc signing 只是为了本地可执行性，不代表发布者签名。

若服务端必须回退到不含 compatibility/header contract 的版本，必须先暂停受影响的 GitHub Pre-release。已安装客户端将停留在本地恢复页，不接受替代 Origin、HTTP fallback 或远程升级 URL。

## 验证状态

仓库级验证记录在 v0.5.0 验收台账中。当前没有同一候选的 production compatibility verifier 记录，也没有 Windows x64 与 macOS arm64 fresh install / overlay install smoke 和最终 sign-off。因此该 Release 只能表述为可下载的 `Unsigned Experimental Preview`，不能表述为已完成运营验收的正式桌面发行。
